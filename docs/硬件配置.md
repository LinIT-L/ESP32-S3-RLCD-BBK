## 2 板型识别（`hw_cfg.c: detect_board()`）

1. **音频优先**：38/47 命中 codec(`0x18`/`0x19`) → ①；13/14 命中 → ②；都不中再探触摸 15/7 → ③；全不中 → 识别轮询界面，不启动系统。
2. 不用触摸当主判据：触摸排线最易虚焊，误判直接黑屏。
3. 触摸地址候选 `0x15`/`0x5D`/`0x14`/`0x38`；**探触摸前必须先给 RST 低→高脉冲并等就绪**，否则芯片停在复位态必然报"无触摸"（且结论会落盘）。
4. 结果存 NVS（`board_id`+`det_mask`），之后开机不再探测；换板/改线用「设置 → 网络与系统 → 硬件管理 → 重新自检」。

## 4 断电开关（LTC2954-2 + AO3415A，PCB1_3）

串在 **VSYS_OUT(25) → VSYS_IN(24)**，只断模组；充电回路 VBUS→GS4056HDA→VBAT 不经过开关。

| 器件 | 接 | 说明 |
|---|---|---|
| Q1 AO3415A | S=25 · D=24 · G=U6.6 `/EN` | R9 100k 跨 G-S |
| U6.1 VIN | 25 + C4 100nF | 旁路（静态 6µA）|
| U6.2 `/PB` | SW1 非地端，**中间不串任何器件** | 纯机械开机，不经过 MCU |
| U6.3 ONT | C5 47nF→GND | 开机按住 ≈0.3s |
| U6.5 `/INT` | GPIO44 | 开漏；固件经 input.c 轮询作电源键 |
| U6.7 PDT | C6 470nF→GND | 强制断电按住 ≈3.1s（固件卡死兜底）|
| U6.8 KILL | IO42 + R10 100k→VCC3V3 | **512ms 内必须为高，不能悬空** |

- 按键通路：SW1→`/PB`（硬件开机）；`/INT`→GPIO44（固件读，低=按下）；GPIO1 已与按键断开、固件不读。【实测 2026-11-21】
- **D1 必须不装**：D1 把 `/PB` 接回 GPIO1，断电瞬间会把 `/PB` 拽低 ⇒ 2954 误判再次按键 ⇒ 断电后 1.2~6.5s 自己开机。装在旧板上用飞线把按键接到 `/PB`。副作用：`pbsim` 失效（只驱动 GPIO1）。
- **Q1 空贴 = 永久断电**（R9 把栅极拉到 VSYS）；此时需 24↔25 短接才有电。
- 定时换算：`C[nF] ≈ 0.156 × (t[ms] − 1)`；100nF≈0.65s · 220nF≈1.4s · 470nF≈3.0s · 1µF≈6.4s。C6 必须 > 固件长按 2s、且不能到 6.4s。用 X7R/X5R（Y5V 掉容 80%、钽/电解漏电大）。
- `hw_off`（NVS `os_settings`，默认 1）：1 = 确认/屏保到点拉 KILL 真断电；0 = 只深睡。

## 5 外挂 RTC（DS3231MZ+，PCB1_3）

主时间源：内部 RTC 日漂几十秒；DS3231 封装内 MEMS + 温补（±5ppm ≈ 13s/月），无需外接晶振，整机断电后靠 VBAT 走时。

| 脚 | 接 |
|---|---|
| 2 VCC | 3V3 + C7 100nF |
| 6 VBAT | **直连模组 23 脚 VBAT（主电池正极）**，不串电阻 |
| 7/8 SDA/SCL | GPIO5 / GPIO13（与触摸同一条 I2C_NUM_1 @100kHz），地址 `0x68` |
| 1 32kHz · 3 INT · 4 RST | 不接 |

- VCC 与 VBAT 都要接；⛔ VCC 不能接电池（永远判不出掉电），VBAT 不能悬空。DS3231 VBAT 允许 2.3–5.5V。
- 上拉 R5/R11 4.7k→**3V3（断电域）**，与触摸共用；⛔ 不能接电池常电（断电后经保护二极管倒灌）。
- ⚠ 主电池直连 VBAT ⇒ 换/拔电池时间归零（取舍：不加 CR1220，省厚度）。电池高于 VCC 时常态从 VBAT 取 ~3µA。
- 校时策略（`svc_rtc`）：**芯片存 UTC，系统只当秒表**。开机 OSF=0 且系统时间无效 → 注入；每 60s 联网以系统回写芯片、离线差 >1s 用芯片修系统；手动设时/关机前各写一次；运行中读时间只用 `time(NULL)`。
- ⛔ 不自建 I2C 总线（用 `i2c_master_get_bus_handle()` 拿 `touch_panel` 建好的）；⛔ 本 IDF 无 `timegm()`，读用 `days_from_civil()` 算术，写用 `gmtime_r()`；上电先读 `0x0F` 的 OSF，写时间成功后清 OSF。
- 校准源只用 NTP（GPS 当前不入时间链路）。开关：设置 → 硬件管理 → 时钟；检测不到芯片则整条链路跳过。

## 6 外围器件与缺装后果（PCB1_3）

| 位号 | 作用 | 缺装后 |
|---|---|---|
| R9 100k（Q1 G-S） | `/EN` 上拉 + 关断偏置 | 栅极浮空 ⇒ 关不断 |
| R10 100k（KILL） | 常态高，满足 512ms 窗口 | 随机断电；冷启动 3V3 慢于 512ms ⇒ 开机即断 |
| R5/R11 4.7k（I2C） | DS3231 上拉 | 内部 45k 拉不高 ⇒ 读时间失败 |
| C5 47nF / C6 470nF | ONT 0.3s / PDT 3.1s | 蹭一下就开机 / 按一下就断电 |
| R12 10k（LCD_RST） | 屏复位上拉 | 上电不亮 / 花屏 |
| R1/R2 5.1k（CC1/CC2） | USB-C 受电识别 | 插电脑无反应 |
| C3 22µF（3V3） | 3V3 储能 | TF/GPS 瞬时掉压 ⇒ 复位或花屏 |
| D2 TVS（+5V） | 热插拔浪涌钳位 | 少一层防护 |
| C4 100nF（VIN） | 旁路 | 影响小 |

**充电状态**：模组 28/29（CHRG/DONE）在 Gerber 上悬空 ⇒ 本板读不到，`.chrg=-1`，一律报"未充电"。
⛔ 不要把 CHRG 引到 44（那是 `/INT`，填了会把按键当"充电中"，状态栏误跳闪电）；单线三态要 ADC 编码，44 非 ADC 脚 ⇒ 不做。改板时引到空闲 ADC 脚再改 `.chrg`。

## 9 外设硬件事实（软件实现见《系统开发》）

**屏 ST7305**：400×300 1bpp 反射，无背光，断电保画面。① 的 RST **不接 GPIO**（仅 10k 上拉 R12）；②③ RST=GPIO41 由固件拉高（③ 另有 R7 10k）。
⛔ `(1ULL<<rst)` 必须带 `>=0` 保护，否则 abort 重启循环。

**触摸**：CST816/836U，I2C_NUM_1 @100kHz。单指；双指只左右半屏各报一点【推断，未真机验证多点】。② 无触摸。I2C **无外部上拉**（见 §11）。

**SD/TF**：SDMMC 1-bit；CMD/D0 各 10k→3V3，卡座 CD(DAT3) 10k→3V3。软件按 400kHz→25M/20M/5M/400k 梯度挂载。
⛔ 深睡 hold SD 三脚 ⇒ 开机必须 `gpio_hold_dis`，否则认不到卡（只能断电）。

**音频**：① ES8311+ES7210 在模组内，I2S/codec I2C 不引出；③ **NS4168**（ESOP8 I2S 数字功放，无 MCLK/I2C/录音）。
功放使能 **GPIO46 高有效**；⛔ 46 是 strapping，禁内部上拉；③ 有 R15 100k 上拉 ⇒ 上电默认导通，固件要尽早拉低（防爆音省电），播放时拉高。

**震动**：TM6604（SOT23-6）+ 1508 LRA。EN(U4.6) 经电阻**常开**到 VBAT（① R3 10k / ③ R16 10k），固件管不着；PWM ① = GPIO8、②③ = GPIO48。VDD 2.7–5.2V；EN/PWM 5V 容限。
内置 H 桥 + 主动制动 + 自动谐振跟踪（140–220Hz）⇒ **不需要续流二极管，也不用按谐振点调频**。⛔ 禁 `gpio_reset_pin`、禁浮空。

**电池/充电**：③ 分压 R14 200k/R13 100k→GPIO4（÷3.0，固件常量 3.10）；① 走模组内 GPIO3。满电取 30 天峰值，空 3300mV。充电器：① LGS4056HDA（模组内）· ③ TP4057（只接 LED）。

**GPS**：MAX-M10S-00B-01，UART1 重映射（不占 UART0）。① TX/RX = 41/14（模组 34/22 脚），UART0(43/44) 走排针不冲突。6 档自动波特率 38400→9600→115200→57600→230400→921600。电源常通，省电靠 `UBX-RXM-PMREQ`（待机 ≈46µA）。⛔ backup 不保留配置 ⇒ 睡醒重认，不做 `UBX-CFG-PRT`。GSV 默认 5s/次，≥38400 时用 `UBX-CFG-VALSET` 提到 1Hz。

## 11 不能撞的脚

- **8 / 48 两板对调**：① 震动 8 + I2S DOUT 48；②③ 震动 48 + I2S DOUT 8。
- **GPIO40 双义**：②③ LCD CS；① I2S MCLK。
- **SD 脚位**：① 15/16/17；③ 38/21/39。③ 的 15/17 只到 LCD FPC（触摸）；① 触摸走 5/13/12/6。
- **① 无 CHRG**；GPIO44 是 `/INT`（电源键），不能当充电检测；GPIO42 让给 KILL ⇒ 外部 JTAG 不可用。
- **GPIO2 / GPIO43 是扩展脚**，固件不占用。
- **② 的 PWR 不是 GPIO**（接电源锁存 U3/ECJ23001，长按硬件断电、单击开机，固件读不到）；可读只有 BOOT(0) 与 KEY(18)；`btn_pwr=18` 仅用于深睡 EXT1 唤醒与门控。
- ⛔ 改引脚前全工程搜"这个号还有谁在用"：撞脚现象常与元凶无关（EXTINT 设 8 ⇒ 一直震；MCLK 设 40 ⇒ 微雪全黑）。
- **I2C 无外部上拉**：两块自研板的触摸 5/13、codec 38/47 只靠模组内部弱上拉。I2C 偶发 NACK / 触摸失灵 / codec 探测失败，先补 4.7k 到 3V3。

## 12 换板

直接换板开机即可（`hw_cfg_init()` 探指纹定板型，不重编、不选板）；探不到 → 设置 → 硬件管理 → 重新自检；仍失败沿用 NVS 上次成功板型（不变砖）。三块板共用 `dist/merged_16mb.bin`。
