# 模块地图

> 只用于定位代码。函数 / 接口 / 细节自己搜索，规范看手册。

## 分层（只允许上→下，`tools/check_deps.py` 守卫）

`apps → system → services → drivers`

| 层 | 目录 | 放什么 |
|---|---|---|
| 入口 | `main/` | 启动编排、串口控制台（remcon）|
| apps | `components/apps/` | 应用页 `pages/page_*`、应用管理 `pages/am_*`、商店、Lua 桥 `lua_bridge/`、注册表 |
| system | `components/system/` | OS 内核与页面栈、input、power_mgr、engine_manager、app_board |
| services | `components/services/` | 网络、蓝牙、音频、触觉（`haptic` 效果库 + `vibrator` 驱动）、存储、时间、日志、LPK、USB |
| ui / libs | `components/ui/`、`components/libs/` | 绘图与字库、软键盘、壁纸；Lua VM、工具库 |
| engines | `components/engines/` | 模拟器与阅读器（`engine_api` 为唯一 facade）|
| drivers | `components/drivers/` | 引脚、屏、触摸、电池、GPS、TF |

## 定位提示

- 引脚 `drivers/board_pins/` · 屏 `drivers/st7305/` · 触摸 `drivers/touch_panel/` · 分区 `partitions.csv`
- Lua API 真相源 `apps/lua_bridge/luat_lib_*.c` · 页面与弹窗 `system/os/kernel/` · 输入 `system/input/`
- 应用清单 `apps/apps_registry.c` + `apps/lua/apps/` · 商店 `apps/pages/am_store*.c`
- 引擎接入 `engines/engine_api/` · 存储 `/sdcard` 挂载 `drivers/sd_scan/`
