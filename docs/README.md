# LinTOS 文档中心

> ESP32-S3 + ST7305 400×300 1bpp 反射屏。**一个固件通吃三块板**（小智 / 微雪 / 标准扩展）。
> 本页是全部文档的索引 —— 找不到东西先看这里；AI 会话的入口规则在根目录 [AGENTS.md](../AGENTS.md)。

```
docs/
├── README.md          ← 本页（唯一入口）
├── 手册/              六本核心手册（系统怎么跑、怎么写、怎么发）
├── 规范/              六份短规范（随时对照，不是通读材料）
├── 专题/
│   ├── 应用资料/      一个应用一份实现说明（7）

└── diagnostics/       临时诊断代码登记处（1）
```

## 6 三条真相源

代码永远优先于文档：

1. **引脚** = `components/drivers/board_pins/board_pins.c`
2. **分区** = `partitions.csv`
3. **Lua API** = `components/apps/lua_bridge/luat_lib_*.c`（跑 `tools/lua_api_doc.py`）

| 内容 | 位置 |

| 短规范 / 硬规则 / 格式规格 | `规范/` |

| 跨应用的机制 | `专题/功能专题/` |
| 一次性过程记录（实施/审查/验收）| **不落盘** —— 结论直接写进上面任一位置 |

改名 / 合并时**同一次改掉所有引用**，不留指针文件、不留 `reports/`、不留 `archive/`。

## 8 烧录

- 换版本：整片 `0x0` 刷 16 MB
- 只改 C：`0x60000`　只改 Lua：`sync_apps.py` 后刷 `0xC00000`
- 带 Lua 应用出整片：`LINTOS_BAKE_LUA_APPS=1 bash merge_flash.sh`

> ⚠ 烧之前先核对 `dist/merged_16mb.bin` 是不是当前构建的产物 —— 它可能已过期，
> 详见[故障排查](规范/故障排查.md) §14。

## 9 维护

- 改代码就在**同一次改动**里更新对应手册；新增 Lua API 必须重跑 `tools/lua_api_doc.py`。
- 一个知识点只有一个权威位置，别处用链接引用。
- 本页是唯一索引，新增文档要在这里登记。
- 文档质量约定见[文档规范](规范/文档规范.md)，AI 会话规则见 [AGENTS.md](../AGENTS.md)。
