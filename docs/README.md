## 读文档三条铁律

1. **规范看根目录，过程看 archive。** 冲突时**以代码为准**。
   ⛔ **不要采信代码里的历史注释** —— 本仓大量注释还写着旧板引脚（`audio_player.c` 仍写 `I2S_BCLK=GPIO9`、
   `vibrator.c` 仍写 `IO46=VON`），一律以 `小智S3核心模块-引脚调整.md` 为准。
2. **API 以注册块为准**：Lua 在 `components/apps/lua_bridge/*.c` 注册段；C 在 `components/system/os/include/os.h`。
3. **数字必须有实测出处**（`readelf` / `idf.py size` / 串口日志），不接受"印象值"。
