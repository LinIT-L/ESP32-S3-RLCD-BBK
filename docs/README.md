## 读文档的三条铁律

1. **规范看权威区，过程看记录区。** 记录区的结论若与代码不符，**以代码为准**，并回来修文档。
2. **API 以注册块为准。** Lua 的 `app.*` 真实清单在 `components/apps/pages/page_lua.c` 的注册段；
   C 侧契约在 `components/system/os/include/os.h` 与 `os_internal.h`。文档与它们冲突时先改文档。
3. **数字必须有实测出处。** 内存 / 尺寸 / 性能类结论须给 `readelf` / `idf.py size` / 串口实测来源，
   不接受"印象值"。⚠ `LinTOS.map` 的**文本正则解析不可靠**（会把 section 填充当符号），
   归属分析请用 `readelf` / `nm` 或 `mem_iram_attr.py`。
