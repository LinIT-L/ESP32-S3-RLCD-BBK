## 一、这个扫描到底有什么用

ESP32-S3 的 SDR 通路能抓 **2.2–2.7 GHz** 的原始 I/Q，而 **2.4 GHz 恰好是所有人都在用的公共频段**。
所以它的作用就是回答一句话：**"我周围 2.4G 频段现在被谁占了、占了多宽、什么时候出现。"**

具体能解决的现实问题：

| 场景 | 怎么用 |
|---|---|
| 自家 WiFi 老是卡 | 看哪条信道（1/6/11）被邻居占满 → 把自己的路由器换到空的那条 |
| 判断蓝牙手柄/耳机在不在广播 | BLE 固定在 2402 / 2426 / 2480 三条广播信道，看到这三处有窄线就是有 BLE 设备在发 |
| 排查莫名其妙的掉线 | 微波炉、无绳电话、无线摄像头会在 2400–2483 拉一条**宽带糊状**的噪声 —— 一看就知道不是 WiFi |
| 检查自己的设备有没有在发射 | 关掉某个设备前后对比，看它那几条线是否消失 |
| 教学 / 直观感受 | 第一次"看见"空气里的信号 |

**它做不到什么（必须说清楚，免得误判）：**

- ❌ **不能解码内容**：只看能量，看不到是谁的数据、也解不出包。
- ❌ **没有绝对功率**：本项目没做功率标定，所以纵轴是"**高于本底多少 dB**"，不是 dBm。
- ❌ **瞬时带宽只有 80 MHz**：一次只能看 80MHz 宽（2397–2477MHz 这种量级），要看别的频段得**改中心频率**。
- ❌ **只有 2.2–2.7 GHz**：看不到 5G WiFi、也看不到 433M / 315M 遥控。
- ❌ **本机（微雪这块板）没有触摸芯片**，只能按键操作。

## 二、判读依据（"扫出来的东西是什么"）

这张表就是应用里**要能给出判断**的依据；屏幕上的"信道标注条"（`B 1 B 6 11`）就是它的可视化版本。

| 屏幕上的现象 | 判断 | 依据 |
|---|---|---|
| 2412 / 2437 / 2462 MHz 附近各有一块**约 20MHz 宽、顶部平坦、长期稳定** | **WiFi 路由器的 ch1 / ch6 / ch11** | 2.4G WiFi 每信道 20MHz，中心就是这三个（不重叠的常规选择） |
| 上述块**宽到 40MHz**（跨两格） | WiFi 开了 **40MHz 绑定** | 802.11n/ac 的 40M 模式 |
| **2402 / 2426 / 2480** 三处各一条**很窄**的线、**间歇出现** | **BLE / 蓝牙设备在广播**（手柄、耳机、手环、信标） | BLE 规范只用这三个广播信道，且广播是间歇的 |
| 窄线**位置来回跳**、间隔不规律 | **经典蓝牙 / 2.4G 无线鼠键**的跳频 | 跳频系统的特征 |
| **2400–2483 整段抬高、形状糊、无明显信道结构** | **微波炉 / 无绳电话 / 劣质开关电源**等宽带噪声源 | 宽带非通信辐射，没有信道形状 |
| **只有中心频率处一根尖峰不动** | **零中频 DC 残留**，不是真信号 | 直接下变频必然有 DC；换中心频率它会跟着走 |
| **跨度两端同时、对称地抬高** | **带边 / 镜像**，不是真信号 | 把中心频率挪一下：跟着走的都是假的 |
| 什么都没看到 | 该段确实安静，或**增益太低** | 点顶栏"自动/手动"切手动并调高，或检查是不是没插天线 |

> **判断真假信号的通用手法**：**改中心频率**。真信号在频率轴上"位置固定、不随中心走"；
> 镜像/DC 会**紧贴中心**跟着跑。

## 三、功能清单（按优先级）

### P1 基础可用（**已完成**）
- ✅ 五分区版式：顶栏 / 谱图 / 频率轴 / 信道标注条 / 瀑布 / 底栏
- ✅ 自动量程（以本底为 0，刻度 0/20/40/60），细线谱线 + peak-hold 点线
- ✅ tracking marker（▼ 自动跟最高峰）+ 反白读数
- ✅ 信道标注条：WiFi ch1/6/11 + BLE 广播三信道
- ✅ 中文界面、顶栏四槽等分居中
- ✅ 跨度 80/40/20/10M 可切；平均 1/4/16 可切；增益 自动↔手动

### P2 测量能力（下一步）
| # | 功能 | 价值 |
|---|---|---|
| P2-1 | **可移动 marker + Δ 相对测量**（左右键移动，第二 marker 显示差值） | 能测"两个峰差多少 dB / 隔多少 MHz" |
| P2-2 | **峰值表**：列出最强的 5 个峰的频率 + 相对强度 | 不用在图上找，直接读数 |
| P2-3 | **瀑布整屏**（一键切换）；peak-hold 清除 | 看历史更方便 |
| P2-4 | **暂停 / 单次捕获** | 定格分析 |

### P3 自动判读（这个应用真正的"智能"）
| # | 功能 | 价值 |
|---|---|---|
| P3-1 | **自动贴标签**：按第二节的判据，在峰上直接标 `WiFi6` / `BLE` / `宽带` | 不用背表，屏幕直接告诉你是什么 |
| P3-2 | **WiFi 信道占用评分**：13 条信道各给一个"占用度"，推荐最空的 | 直接解决"路由器该用哪条信道" |
| P3-3 | **稳定度**：连续 N 帧都出现 → 标 `常发`；一闪一闪 → 标 `间歇` | 区分 AP 和手机热点 |

### P4 扩展
频段预设（2.4G 全段 / WiFi 13 信道 / BLE）· 大数字显示 · 阈值蜂鸣 · CSV 导出到 TF · 截图存卡

### P5 工程优化
- 进页加速：先出画面再初始化；蓝牙改 `suspend/resume`（省 1–2s）；FFT 表开机预建
- 渲染/DSP 搬核心 1（双缓冲）—— **先量清瓶颈再动**（可能 SP I 刷屏才是大头）
