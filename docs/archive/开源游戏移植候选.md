### 0. 先定筛选标准（决定成败的那一条）

**屏幕只有黑/白两色、400×300**，运行时只有 Lua + `app.*` 桥（没有引擎、没有 C#/Rust/Godot 运行时）。

| 判据 | 能好看 | 一定糊 |
|---|---|---|
| **素材原始分辨率** | 低分辨率像素画（精灵 ≤32px、瓦片 ≤24px） | 高清/灰度贴图（60px+ 带噪声渐变） |
| **色阶** | 本来就是 1bit / 少量硬边色块 | 靠明暗渐变表达体积 |
| **玩法数据量** | 数据驱动、规则少 | 内容海量（几百种道具/怪物） |
| **源码语言** | **Lua**（TIC-80 / PICO-8）→ 换绘制 API 即可 | C#/Rust/C++（要重写） |

**结论**：优先 **TIC-80 / PICO-8 生态的 Lua 小游戏** —— 它们和你的硬件是**同一类约束**（低分辨率 + 限制色板 + Lua），移植成本最低、画风天然对得上。
