> 本文是**调研结论 + 复刻方案 + 需要你拍板的取舍**。素材已存 `apps/biossim/ref/`（含出处与授权说明）。

## 1. 为什么"一点都不像"——三条根因（都有数值）

| # | 根因 | 真机 | 我之前做的 |
|---|---|---|---|
| 1 | **选中行配色** | Award：**红底 `#AA0000` + 黄字 `#FFFF55`**；AMI：**深蓝底 `#000080` + 白字** | 黑白反色 ❌ |
| 2 | **数值列颜色** | 数值是**独立颜色**（Award 黄 `#FFFF55` / AMI 黑 `#000000`），与标签不同色 | 与标签同色 ❌ |
| 3 | **选项名/层级是编的** | 真机 IFR 导出：`SATA mode = IDE Mode / AHCI Mode / RAID Mode`、`TPM 2.0 UEFI Spec Version = TCG_1_2 / TCG_2`、`AMD fTPM switch`、`SVM Mode`、`XHCI Hand-off`…，还有**只读信息行**（`[Info]`）与**段落分隔行**（`--- Boot Option Priorities ---`） | 名字部分对、**信息行/分隔行全缺** ❌ |

底色也不同：Award 是 `#0000AA`（我用 `#00007a`）、AMI 是灰底 `#C0C0C0`；外框 Award `4px double` 白、AMI `3px solid` 深蓝；字体 Award `Courier New` / AMI `Lucida Console`。

## 3. ★ 需要你拍板：颜色 vs 掌机 1bpp（这两条是冲突的）

掌机屏是 **1bpp 单色**，"红底黄字"物理上做不到；但你要"非常像"。三种处理：

| 方案 | 电脑版（学习/参照） | 掌机版（实际运行） | 评价 |
|---|---|---|---|
| **A（推荐）** | **完全用真机配色**（Award 红底黄字 / AMI 深蓝白字 + 彩色数值 + 双线框） | 1bpp 映射：**选中行整行反色**、数值列改用 **下划线/括号** 区分、外框用双线 | 各取所长：电脑上"像素级像"，掌机上"结构/选项 100% 一致、黑白可读"。**同一份菜单树驱动** |
| B | 也做纯黑白（两版一致） | 纯黑白反色 | 最简单，但电脑上也永远不像 —— 与你现在的诉求相反 |
| C | 只做电脑版彩色 | 暂不做掌机版 | 最快看到"非常像"，但掌机 App 这条线悬空 |

**我建议 A**：一份数据（真机菜单树）驱动两个皮肤 —— 电脑版**照真机配色**、掌机版**1bpp 映射**。
这样"像不像"的问题在电脑上彻底解决，掌机上也不违反单色约束。

## 4. 复刻方案（照真机，不再自创）

1. **数据驱动**：渲染器改成**由 JSON 菜单树驱动**（字段与真机 IFR dump 一致：
   `tabs[].items[] = {type: item|submenu|text, label, value, options[]}`）→ 以后加真机型号 = 加一个 JSON。
2. **版式**（照真机骨架）：`header`（标题栏）→ `nav-bar`（一级菜单，active 高亮）→
   `content-area`（`label ……… value` 两列，选中行整行高亮）→ `footer`（按键提示）→ 弹窗（选值 / 保存确认）。
3. **配色**：A 方案 —— 电脑版用 §1 的两套真机配色；掌机版 1bpp 映射规则：
   - 选中行 → **整行反色**（黑底白字／白底黑字）
   - 数值列 → 用 `[AHCI]` **方括号**（真机 AMI 的写法）区分，不靠颜色
   - 外框/分隔线 → 双线/实线
   - 只读信息行 → 前缀 `:`（真机的 `:--:` 风格）
4. **学习任务**沿用现有 8 个场景，但**判定改绑真机选项名**（如 Win11 检查 `SATA Mode`/`TPM State`/
   `TPM 2.0 UEFI Spec Version`/`Secure Boot` 的真机取值）。

## 5. 需要你执行的一条命令（想拿"真机像素级截图"当参照的话）

本机 `brew` 被 Xcode 许可拦住（与 `/usr/bin/git` 同一个 shim 问题），所以我**装不了 QEMU**：

```bash
sudo xcodebuild -license accept
```

执行后我就能 `brew install qemu` → 用**开源 OVMF/EDK II 固件**跑真实 UEFI Setup →
截真实界面（**开源固件，无版权问题**，比真机 dump 更适合当公开参照）。

**不执行也能做**：§1 的配色数值 + §2 的真实菜单树已经够把"像"做到位（差的是像素级细节）。
