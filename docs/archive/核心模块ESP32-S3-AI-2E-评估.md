## 〇、这块板是什么（先把边界划清）

| 归属 | 器件 | 说明 |
|---|---|---|
| **核心模块** | **U1 `ESP32-S3-AI-2E`**（47 脚） | 你说的"核心模块"。**它自带电源管理**（见下） |
| 底板 | U3 `ML307R`（LCC-LGA-109，17.7×15.8mm） | 4G Cat.1 模组 + SIM1 + ESD(D2/D3/D5) + 天线座 RF1(IPEX) |
| 底板 | U5（SOT-23-5）+ L1 + C21 + R12/R13 | 升压，SWVI → **VBAT_4G（3.8V 级，4G 的 PA 要）** |
| 底板 | USB1(Type-C) + R1/R2 | USB 座 + **5.1k CC 下拉** |
| 底板 | SW4 / SW5 / SW6 | 电源拨动开关 / RESET / BOOT |
| 底板 | CN1~CN7 + FPC2 + H1 | 喇叭、电池、预留 IO、双麦、耳机座(带插入检测)、**两路 LCD 接口**、调试排针 |
| 底板 | Q1/Q2/Q3 + 阻容 + LED1/2/3/5 | 背光开关、4G UART 电平转换(1.8V↔3.3V)、4G 电源开关、指示灯 |

**关键判断：底板上没有任何充电 IC，也没有独立 3.3V 稳压器**（全板 IC 只有 3 颗：U1 模块 / U3 4G / U5 升压）。
⇒ **充放电、电源路径、3V3 都做在模块里** —— 模块对外只要"VBUS + 电池(VBAT) + 一个机械开关(SWVI/SWVO)"。
这正是"只用核心模块"最省事的地方：你不用再画充电和电源路径。

## 一、模块自己提供什么（从它引出的 47 脚反推）

| 类别 | 模块引脚 | 说明 |
|---|---|---|
| 电 | `2:3V3` `23:VBAT` `24:SWVI` `25:SWVO` `26:VBUS` | 电池进、开关进/出、USB 进。**3V3 是模块输出**（实证：全板 IC 只有 U1 模块 / U3 4G / U5 升压，没有独立 3.3V 芯片；`3V3` 网上唯一的来源就是 `U1.2`，其余全是 LED / 上拉 / LCD 这些消耗方） |
| 显示 | `IO4_SCL` `IO5_SDA` `IO6_DC` `IO7_CS` `IO15_RES` + `IO9_BLK` | **标准 4 线 SPI LCD**（SCL/SDA 是厂商对 SCLK/MOSI 的叫法）+ 背光（经 Q1 驱动） |
| 音频 | `VOP/VON`(喇叭) `OUTP/OUTN`(耳机) `MIC1P/N` `MIC2P/N` `IO16_INSERT DET` | **麦克风是模拟差分、喇叭/耳机是功放输出** ⇒ **模块内置 audio codec + 功放**，不是裸 I2S |
| USB | `13:DN` `14:DP`（模块脚号，即 GPIO19/20） | 原生 USB（烧录 + 串口日志） |
| 控制 | `27:BOOT` `3:RESET` `36:U0RXD` `37:U0TXD` | 下载/复位 + UART0 调试口 |
| 4G | `IO17_ML307_PWR` `IO1_TXD_ESP32-S3` `IO42_RXD_ESP32-S3` | 控制 4G 的电源/UART（底板再用 Q2 做 1.8V↔3.3V 电平转换） |
| 其它 | `IO13_LED` `IO2_RESERVE` | 状态灯、预留 IO |

**没有引出的**：TF/SD、触摸屏 I2C、GPS、震动电机、电池 ADC —— **这些底板上本来就没有，等于模块也没给**。
板上也**看不到 ESP32 的 WiFi/BT 天线**（RF1 只接 4G）→ **必须确认模块自带板载天线**，否则要自己加。

## 二、⚠ 与现有 LinTOS 自制板的引脚对照（最要紧的一节）

现有板（`docs/硬件与IO.md`）vs 新模块，**逐脚都不同**：

| GPIO | 现有 LinTOS | 新模块 | 冲突 |
|---|---|---|---|
| 4 | 电池 ADC (ADC1_CH3) | **LCD SCL** | ✗ |
| 5 | LCD DC | **LCD SDA** | ✗ |
| 6 | 空闲 | LCD DC | — |
| 7 | 触摸 SCL | **LCD CS** | ✗ |
| 9 | I2S BCLK | **LCD 背光** | ✗ |
| 13 | 预留 I2C SDA | 状态灯 | — |
| 15 | 触摸 SDA | **LCD RESET** | ✗ |
| 16 | I2S MCLK | 耳机插入检测 | ✗ |
| 17 | 触摸 INT | 4G 电源使能 | ✗ |
| 42 | 震动 PWM | 4G UART RX | ✗ |
| 43/44 | **GPS** UART1 | UART0 调试口 | ✗（可用矩阵改到别的脚） |
| 19/20 | USB | USB | ✓ 一致 |

**结论：换成这个模块 = 固件引脚映射要重做一遍 + 底板重画**，不是"换个模块插上就行"。
（`components/system/input`、`st7305`、`sd_scan`、`board_battery`、`gps`、`vibrator`、`tone_player` 的 pin 全要改。）

## 三、IO 预算（够不够）

| | 数量 | 明细 |
|---|---|---|
| 模块占掉 | 13 | GPIO 1,2,4,5,6,7,9,13,15,16,17,42（+USB 19/20、+UART0 43/44、+BOOT 0） |
| 现有固件需要 | ~24 | LCD 5 · 触摸 4 · SD 3 · I2S 5 + MIC 1 · 震动 2 · 电池 ADC 1 · GPS 3 |
| 模块的 LCD 已给 | 5+1 | IO4/5/6/7/15 + IO9 → **LCD 和触摸屏不一样，触摸还得另找 4 个** |

`ESP32-S3` 可用 IO ≈ 33（扣 flash 26-32、PSRAM 33-37）。模块占 13 → 剩 ~20。
**够用但没有富余**。两个省脚办法：
1. **音频用模块自带的**（模块已集成 codec+功放+双麦）⇒ 直接省 6 个 IO，还省掉 ES8311/NS7210/NS4168 那一套代码；
2. 触摸若用模块的 LCD 一体屏（带触摸的 SPI 屏），触摸也能复用同一条 SPI（省 2-3 脚）。

## 四、打板/换板前**必须处理**的 5 条（网表实证）

| # | 问题 | 证据 | 处置 |
|---|---|---|---|
| **E1** | **ML307R_RESET 悬空** | `ML307R_RESET` 只有 1 个引脚 `U3.15` | 4G 模组复位脚**必须**上拉到它的 `VDD_EXT`(1.8V)，最好再引到 MCU 可控；悬空会**随机不启动** |
| **E2** | **VBUS 上没有任何电容** | `VBUS` = LED3.2 / U1.26 / USB1.A4,A9（无电容） | USB 输入加 **≥1µF + 0.1µF**（热插拔浪涌/掉电复位都要它） |
| **E3** | **VDD_EXT 无去耦** | `VDD_EXT` = R15/R16/R17 + U3.24 | ML307R 的 1.8V 输出脚按手册加 **1µF**（它同时给 3 个上拉供电） |
| **E4** | ML307R 的 **USB_DP/DM 悬空** | `USB_DP`←U3.59、`USB_DM`←U3.60 各 1 脚 | 不做 4G 固件升级可接受；要升级就引 2 个测试点（别一直悬空） |
| **E5** | **只有 4G 有天线，ESP32 没有** | RF1 只接 `ANT_MAIN`→U3.35 | **确认模块自带 WiFi/BT 天线**；没有就得留 IPEX/陶瓷天线位置 |

> 工具还报了两条 `疑似重复放置`：`C16+C17`(C1206)、`C2+C18`(C0603) 都在 `VBAT_4G` 上。
> **这条是误报**——4G 的 VBAT 本来就要并联一大排电容（100µF/22µF 级 + 0603 小容值），
> 不是"复制粘贴多放了"。但请顺带确认 BOM 容值不是真抄重了。

## 五、画新底板时**不能省**的（底板上看着不起眼，少了就出问题）

1. **BOOT + RESET 两个按键**（SW5/SW6）—— 少一个就进不了下载模式 / 复位不了。
   另外 EN 侧通常配 10k 上拉 + 1µF（模块内若有就免），IO0 侧建议 10k 上拉。
2. **USB-C 的 5.1k CC 下拉 ×2**（R1/R2 5.1k）—— 少了 Type-C 电源不给电/识别不了。
3. **电源拨动开关**接在模块 `SWVI`(24) ↔ `SWVO`(25) 之间（底板 SW4 就是这个）。
4. **模块 3V3 入口的去耦**（板上 3V3 侧只有 LCD/灯/上拉，没有模块近端大容）。
5. **模块的 `U1.22/28` 与 `U1.29/34` 两组网络要照原样复刻**：
   `22/28` 两脚互连（`$1N75180`）；`29/34` 接 VBUS 指示灯支路（`VBUS→LED3→R8→$1N58593`）——
   这两处是模块内部要求的外部接法，新底板漏了可能"指示灯不亮"或工作异常。

## 六、必须要到的资料（否则没法开工）

| 资料 | 为什么必须 |
|---|---|
| **模块引脚定义表**（脚号 ↔ GPIO 名 ↔ 功能） | 网表只有网络名，拍不了 PCB |
| **PSRAM/Flash 规格** | 现有固件 `CONFIG_SPIRAM_MODE_OCT`（8MB octal 80MHz）占 GPIO33-37；**若模块是 quad PSRAM 或容量不同，固件要改配置，甚至跑不起来** |
| **内置 audio codec 型号 + 控制接口** | 现有固件是"外部 ES8311(I2C)+I2S 或 NS4168"，模块内置 codec ⇒ 驱动要重写 |
| **供电能力**：3V3 输出电流、充电电流、支持的单节电池类型 | 决定了你能挂多少外设（LCD 背光 + SD + 触摸 + 震动都是电流大户） |
| **模块自带哪些去耦/天线/上拉** | 决定底板还要补多少（比如 EN 的 RC、IO0 上拉） |
| **模块的机械图（邮票孔间距/外形）** | 底板封装 |

> 若供应商给的是**立创EDA 专业版工程（`.epro2`）**，直接给我 —— 里面的 `project2.json`
> 有官方完整说明书 HTML（默认电压/上电时序/电流表/复刻须知），比啃网表准得多。

## 七、一句话总结

**能这么干，而且比现在更省事**（电源/充电/音频都收进模块了），但代价是：
① **引脚全变**→ 固件 pin map + 底板一起重做；
② **必须补 5 条**（4G 复位上拉、VBUS 电容、VDD_EXT 电容、模块 3V3 去耦、确认 WiFi 天线）；
③ **必须先拿到模块规格书**（尤其 PSRAM 类型和内置 codec），否则音频和内存两块会卡住。

> 如果只是想"少画电源"，另一条更稳的路：**保留现有底板，把电源部分换成已分析的 TG28/AXP2101 模块**
> （`docs/电源模块TG28-AXP2101-分析.md`）—— 引脚不用动，固件改动只在电源/电量那几处。
