# 频谱仪 UI 改版计划

> 2026-10-01 · 起因：现有界面"太差"—— 信息挤在一行、没有刻度、没有 marker，看不出所以然。

## 1. 参考的开源实现（照结构，不照配色）

| 参考 | 值得抄的部分 |
|---|---|
| **tinySA**（tinysa.org，手持频谱仪的行业标准） | 五分区版式（左参数栏 / 顶部 marker 信息 / 中间测量区 / 底部扫描信息 / 右菜单）；最多 4 个 marker 且带 **R**eference/**D**elta/**N**oise 语义；迹线 3 条（当前/上次/存储）；DISPLAY 菜单：**PAUSE SWEEP · WATERFALL(二次点击放大) · BIG NUMBER · DRAW LINE · SWEEP TIME · SWEEP POINTS**；测量预设 HARMONIC / OIP3 / PHASE NOISE / SNR / **-3dB WIDTH**；扫描有绿色进度线 |
| **PortaPack Mayhem** `ui_looking_glass_app` | 三档扫描（FASTSCAN / SLOWSCAN / SINGLEPASS）；`add_spectrum_pixel` 的 **peak hold + RSSI 参考线**；可移动频率 marker；**信号超阈值蜂鸣**（beep_squelch）；可自定义 f_min/f_max 与频段预设 |
| **1-bit / 电子纸显示惯例** | 只用黑+白，靠**点阵疏密**表达强弱；**反白块**做强调；刻度用短 tick 不用满网格（满网格在 1bpp 下会糊成一团） |

## 2. 现状问题（为什么"差"）

| # | 问题 | 后果 |
|---|---|---|
| 1 | 只有一条 18px 状态行，频率/增益/平均/峰值全挤成一行 | 关键量不突出，扫一眼读不出来 |
| 2 | **没有频率轴刻度** | 看到峰也不知道是哪条信道 |
| 3 | **没有 marker、无常驻读数** | 只能"看图"，不能测量 |
| 4 | **没有 dB 刻度参考** | 强弱无从比较 |
| 5 | 瀑布等高、无时间概念 | 看不出"什么时候出现" |
| 6 | 左右=频率 / 上下=增益 / 确认=平均 这类隐式绑定 | 记不住，也和系统其它页面不一致 |
| 7 | 采集失败/越写只有角落一行小字 | 出问题看不见 |

（另有 **P0 级 bug**：手柄连着时进频谱仪 → 约 2.4s 后 `TG1WDT_SYS_RST` 复位。见 S10。）

## 3. 目标版式（五分区，见对话里的版式预览图）

| 区 | 高度 | 内容 |
|---|---|---|
| ① 顶栏（反白） | 19px | 中心频率（最醒目）· SPAN · RBW · 增益档 · 平均档 · 电池 |
| ② 谱图 | 155px | 左侧 dB 刻度栏 + **点阵网格** + 实填谱线 + **点线 peak-hold** + marker（▼ + 点线 + 反白读数） |
| ③ 频率轴 | 14px | 5 个 tick + 频率数字（中心加粗） |
| ④ 瀑布 | 80px | 1bpp 位图：黑=强 / 点阵=中 / 白=弱；一行=一个时间片 |
| ⑤ 底栏（反白） | 24px | MARK 状态 · PEAK-HOLD 标志 · **反白读数框** · RUN/HOLD |

三处 1bpp 专属技巧（版式图里都画了）：
- **网格在谱线下层**：先画点阵网格，再填谱线 → 谱线自动盖住网格，不需要反色
- **marker 竖线分两段**：谱线上方用黑点线、进入填充区改白点线 → 黑/白背景下都看得见
- **瀑布用点阵疏密**：不依赖灰度也能表达强弱

## 4. 一步一步（每步可独立验收）

| 步 | 做什么 | 验收标准 | 风险 |
|---|---|---|---|
| **S10** | 修 P0 复位：进频谱仪前让蓝牙让出射频（连着手柄时挂起，退出恢复）；`bt_map` 每报必打日志改成计数 | 手柄连着进频谱仪不再重启 | 中 |
| **S1** | 抽渲染层 `sdr_view.c`：几何/分区/居中从 DSP 里剥出来，全工程只留一处 | 编译通过，画面与现状等价（回归基线） | 低 |
| **S2** | 五分区版式：先做 ①②③⑤，瀑布沿用旧绘制 | 抓屏与版式预览一致 | 低 |
| **S3** | Marker：tracking（自动跟峰）+ 可左右移动 + Δ 相对测量 | 移动 marker 读数实时更新 | 低 |
| **S4** | Peak hold 迹线 + HOLD/RUN 切换 | 画面上出现第二条点线 | 低 |
| **S5** | 频率轴刻度 + **全带宽视图**（SPAN 32M/80M 可切） | 一次看到 2412/2437/2462 三条 WiFi 信道 | 低 |
| **S6** | 交互重排：上下开"参数菜单条"，左右=调中心频率 | 不用记隐式绑定 | 中 |
| **S7** | 频段预设：2.4G WiFi / BLE 广播 / 全段扫 / 自定 | 一键跳常用频段 | 低 |
| **S8** | 阈值蜂鸣（有信号响）+ 峰值定格数秒 | 不用盯屏 | 低 |
| **S9** | 截图存 TF（1bpp BMP）+ CSV 导出频谱 | 卡里能看到文件 | 低 |

## 5. 建议顺序

**S10 → S1 → S2 → S3 → S5 → S4 → S6 → S7 → S8 → S9**

先把"会重启"修掉，再做结构（S1）避免后面返工，然后按"看得懂 → 能测量 → 好操作 → 有扩展"推进。

## 6. 明确不做

| 不做 | 原因 |
|---|---|
| 彩色 / 灰度渐变 | 屏是 1-bit 反射式，物理上不支持 |
| 瀑布时间轴刻度 | 占 80px 宽度换不到有效信息 |
| OIP3 / 相位噪声等测量预设 | 没有绝对幅度标定（`dBm` 是假的），做了也是错的 |
| 全屏瀑布作为默认 | 与谱图不能同屏看，做成可切换即可 |
