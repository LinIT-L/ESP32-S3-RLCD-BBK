# LinTOS v1.4 发布材料（GitHub）

## 一、项目简介（README 开头）

### LinTOS · 步步高掌机复刻

基于 **ESP32-S3** 的复古掌机系统，跑在 **400×300 单色反射式 LCD**（ST7305）上 —— 户外可读、低功耗、断电保留画面。

**简单地说：一台能装进口袋的复古掌机 + 学习机 + 运维工具箱。**

> 本项目为个人兴趣复刻与研究，不对应任何商业产品；固件与素材仅供学习交流。
