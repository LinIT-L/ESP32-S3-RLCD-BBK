# LinTOS v1.4 发布材料

## 一、项目简介

### LinTOS · 步步高掌机复刻

基于 **ESP32-S3** 的复古掌机系统，运行在 **400×300 单色反射式 LCD**（ST7305）上 —— 户外可读、低功耗、断电保留画面。

**简单地说：一台能装进口袋的复古掌机 + 学习机 + 运维工具箱。**

内置 **多平台游戏模拟器**（GB/GBC/NES/MD/SMS·GG/ArduBoy，另有文曲星、暴龙机复刻与金手指修改机）、**离线矢量地图导航**、**航班雷达**、**频谱仪**、阅读器、音乐播放器、以及一整套硬件与网络诊断工具。

> 本项目为个人兴趣复刻与研究，不对应任何商业产品；固件与素材仅供学习交流。

## 三、支持的硬件版本（版型说明）

**同一份固件，开机自动识别板型**，无需手动选板。

### ① 小智集成板

主控用**小智 ESP32-S3-AI-2E 模块** —— 该模块**已一体集成**：充电管理、降压、功放、音频解码、麦克风。
外围只需补上屏幕、按键（触摸）、TF 卡等。

### ② 微雪原版

微雪 **ESP32-S3-RLCD-4.2** 成品板（板载齐全，无触摸、无 GPS）。

### ③ 标准扩展板

主控用**官方标准 ESP32-S3 模块**，**充电 / 降压 / 功放 / 解码 / 麦克风按需自行扩展** ——
适合自由配置。

### 识别方式

开机探测各板独有的芯片指纹（I2C 总线上的音频解码芯片 / 触摸芯片等）⇒ 判定板型 ⇒ 套用对应引脚表。
**识别不到的硬件不会去初始化**（例如没焊 GPS 的板子不会占用串口）；
也可在「设置 → 网络与系统 → 硬件管理」里手动开关各项硬件。
