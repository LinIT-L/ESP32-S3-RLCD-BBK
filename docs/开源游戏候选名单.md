# 开源游戏候选名单（给 linit 挑）

> 用途：为 `LinTOS 0.8`（ESP32-S3 + **400×300 1bpp 黑白屏** + **Lua 单文件运行时**）挑一个可移植的开源游戏。
> 整理日期：2026-10-03

## 0. 先定筛选标准（决定成败的那一条）

**屏幕只有黑/白两色、400×300**，运行时只有 Lua + `app.*` 桥（没有引擎、没有 C#/Rust/Godot 运行时）。

| 判据 | 能好看 | 一定糊 |
|---|---|---|
| **素材原始分辨率** | 低分辨率像素画（精灵 ≤32px、瓦片 ≤24px） | 高清/灰度贴图（60px+ 带噪声渐变） |
| **色阶** | 本来就是 1bit / 少量硬边色块 | 靠明暗渐变表达体积 |
| **玩法数据量** | 数据驱动、规则少 | 内容海量（几百种道具/怪物） |
| **源码语言** | **Lua**（TIC-80 / PICO-8）→ 换绘制 API 即可 | C#/Rust/C++（要重写） |

**结论**：优先 **TIC-80 / PICO-8 生态的 Lua 小游戏** —— 它们和你的硬件是**同一类约束**（低分辨率 + 限制色板 + Lua），移植成本最低、画风天然对得上。

## B 档 · **1bpp / 低分辨率最契合（我最推荐先看这档）**

| 项目 | 是什么 | 为什么合适 |
|---|---|---|
| **TIC-80 生态**（`nesbox/TIC-80`） | 开源幻想主机，**128×136 / 16 色 / Lua 为主** | 分辨率比你的屏还小；**源码就是 Lua** → 移植=换绘制 API；开源游戏几十上百个 |
| `edopalomino/pixel-farm` | PICO-8 农场：网格地图 + 精灵动画 | **纯 Lua**、MIT、玩法轻 |
| `erwinbonsma/PicoGarden` | PICO-8 花园（生命游戏） | 纯 Lua、MIT，适合看渲染写法 |
| **`jrob774/gbisaac`**（Isaac GB Edition） | **真正的 Game Boy 1bpp** 版以撒 | ★ 分辨率/色深**完全对得上**（160×144 / 1bit）；可看 1bpp 美术怎么画 |
| **WASM-4**（`aduros/wasm4`） | 160×160 / 4 色极简主机 | 约束极强 → 素材天生适合 1bpp |
| `Pyxel`（`kitao/pyxel`） | Python 复古引擎 128×128 | 素材低分、示例多 |

> B 档的价值：**不是拿来直接跑**，而是拿来**抄美术规格与渲染写法**——它们的精灵/瓦片尺寸就是你的屏该有的尺寸。
