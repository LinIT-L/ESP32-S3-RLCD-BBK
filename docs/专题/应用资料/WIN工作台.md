# 应用资料 · WIN 工作台

> 适用：LinTOS 1.0。C 内置应用。
> 源码：`components/apps/pages/page_winassist.c`（**369 行**）。
> 前身叫「运维助手」，2026-10-15 改名。
> 本文只写**当前实现**；历史过程已归并于此，原报告已清理。

## 1 用途

把掌机当**电脑的远程键鼠 + 命令注入器**：USB 连 PC，点屏幕按钮在 PC 上敲组合键或执行预设命令。
典型场景：没有键盘时重装系统、排查别人的电脑。

## 2 入口与源码

| 项 | 值 |
|---|---|
| 页面 | `components/apps/pages/page_winassist.c` |
| 日志诊断配套 | `components/apps/pages/page_logdiag.c`（采集链路，与本应用同系列演进）|
| 底层 | `usb_hid`（HID 键盘/鼠标）+ CDC 串口，进入时 `os_hid_start()` |
| 分类 | 运维类（应用管家内）|
| 退出 | 返回键退出并**恢复串口** |

## 3 界面结构

```
┌─ 顶部：分类 Tab —— 系统 / 硬件 / 网络 / 维护 / 高级
├─ 中部：当前分类 2 排 × 4 列快捷键（无边框，仅名称）
│        点按 = 发组合键，或 Win+R + 预设命令
├─ 下部：触控板（滑动=鼠标 / 单点=左键 / 长按=右键）
└─ 底部：左键 / 右键（左上圆、右上圆，其余直角，直铺到底）
```

## 4 数据与动作

快捷键表在页面内静态定义：分类 → 8 个按钮 → 动作。动作两类：

1. **组合键**：直接发 HID 报告。
2. **命令注入**：Win+R → 输入命令 → 回车。

> 每个分类 8 项的具体内容**以源码表为准**（本文不抄录，避免与实现不同步）。

## 5 关键约束

- ⛔ **退出必须关 USB HID**，否则串口被占用 → "退出后串口没了"。
- 触控板手势与普通页面不同（滑动 = 鼠标移动），**不要套 `ui_scroll`**。
- 连 PC 时设备处于 USB 复合模式，**烧录要进下载模式或趁枚举窗口**。
- `os_hid.c` / `os_hid.h` 属公共模块，改动会波及其它 USB 应用。

## 6 验证状态

| 项 | 状态 |
|---|---|
| 源码审查 | ✅ 三轮审计 + 两轮复核 |
| 数据链路（采集/编码/回传/超时）| ✅ 源码 + 主机侧脚本验证 |
| **真机（接 Windows PC）** | **❌ 0 项，一条都没跑** |
| 是否存在阻止使用的 P0 | 结论：**无 P0** |

> 所有"可用"结论来自源码与主机侧推导，**没有在真实 Windows 上验证过**。
> 首次上机要按 §7 完整走一遍。

## 7 上机验证清单

1. 接一台 Windows PC → 设备枚举为 HID 键盘/鼠标 + CDC。
2. 逐个分类点按钮（8 项 × 5 类）：组合键是否生效、命令是否执行。
3. 触控板：滑动移动、单点左键、长按右键。
4. 底部左右键。
5. 按返回退出 → **确认 PC 上串口设备恢复**。
6. 中文输入（编码链路在主机侧验过，真机未验）。

## 8 已知限制

- 只针对 Windows；其他系统未验证。
- HID 只支持 US 键盘布局（与收藏夹相同限制）。
