# 应用资料 · 阅读器

> 适用：LinTOS 1.0。C 内置应用 + 独立引擎。
> 源码：`components/apps/pages/page_book.c`（页面，792 行）+ `components/engines/book_reader/`（引擎，约 4400 行）。
> 本文只写**当前实现**；历史过程已归并于此，原报告已清理。

## 1 用途

在 400×300 单色屏上读长文本：书架、翻页、跳转、章节导航、调字号行距、记住读到哪里。

## 2 源码结构

| 文件 | 行数 | 职责 |
|---|---|---|
| `pages/page_book.c` | 890 | 页面：书架、显示设置、交互 |
| `book_reader/book_reader.c` | 3556 | 引擎主体：解析、排版、翻页、进度、菜单 |
| `book_reader/book_flow.c` | 410 | 流程控制（翻页/跳转状态）|
| `book_reader/epub_convert.c` | 435 | EPUB 转换 |
| `book_reader/fb2_convert.c` | 285 | FB2 转换 |
| `book_reader/font_book.c` | 763 | 统一取字（内置 16/24 + TF 卡 LBF）、字号表、系统 UI 字体 |
| `book_reader/gb2312_uni.c` | 99 | GB2312 → Unicode |

**分工**：页面管显示设置与交互；引擎管解析、排版、翻页、进度。

## 2.1 阅读菜单与字体分层（2026-10-31）

阅读器二级菜单（9 项，固定行高 32px）：

```
目录 / 上一章 / 下一章 / 跳到进度 / 加书签 / 书签列表 / 字体 / 字号 / 返回书库
```

- 「字体」「字号」**留在阅读器弹窗内**（linit 2026-10-31 定），与书库「阅读优化」
  共用同一份 NVS 状态，两处改哪儿都一样。
- 所有弹窗用**系统字体**（16px 宋体 + 8×16 ASCII）；只有正文/页码/进度/章节名跟随阅读字体。
  实现方式与理由见 [字体系统规范 §6.4](../../规范/字体系统.md)。
- 绘制只有两个入口：`read_draw_text()`（跟随阅读字体）/ `ui_draw_text()`（系统字体）。
  任何地方**不得**用 `font_book_select()` 临时改全局字号再改回来。
- 字号列表来自 `font_book_size_count()`，即当前字体的真实规格：内置 16/24/32/48，
  fusion8 只有 8/16，ark12 只有 12/24。

## 3 数据存储

| 位置 | 内容 |
|---|---|
| NVS `os_book`：`last_page` / `last_path` | 引擎写的阅读进度 |
| NVS `os_book`：`fs` / `pn` / `mg` / `lh` / `gp` / `in` / `rt` | 显示设置（字号档位/进度条/边距/行高/字距/缩进/旋转）|
| NVS `os_book`：`ftn`（字体**文件名**，空=内置）+ `ft`（旧标记） | 字体选择。**阅读器弹窗与书库共用这一组键**；不再存序号（目录增删会错位）|
| TF 卡 `.pos` 文件 | 每本书的位置，**优先于 NVS** |

`fs` 存的是**档位下标**而不是像素：读回时按当前字体的字号表重新解释，越界收敛到
最大合法档（内置 4 档 / 8px 字体 2 档，同一个下标在不同字体里指向不同像素）。

**恢复顺序**：先读 TF 的 `.pos`；读不到（损坏/换卡）时，若这本书正是"最近阅读"，才用 NVS 页号兜底。

### 3.1 书签与排版解耦（2026-11-01）

书签存在同一个 `.pos` 文件尾部（`prog_bm_t`，每条 **42 B**，上限 **8 条**），
每条只有三样东西：`off`（**源文件字节偏移**）、`page`（当时的页号）、章节标题。

**硬规则**：

| 规则 | 原因 |
|---|---|
| `off` 与排版无关，**永远有效** | 只有它才是书签的锚点 |
| `page` **只在布局未变时**可直接用 | 布局变了页界就变，旧页号指向错误位置 |
| 加载 `.pos` 时书签**必须无条件读入**，只判 `bm_count <= BOOK_MAX_BOOKMARKS` | 见下 |
| 布局变化 → `page` 置 `0xFFFFFFFF`，跳转走 `book_page_for_offset(off)` | 主动触发既有兜底，避免"旧页号碰巧没越界但指错页" |
| 改任何阅读优化选项，**不得**清空或重写书签区 | 设置只影响显示，不影响数据 |

⚠ **曾经的 bug（2026-11-01 修）**：`book_load_progress()` 里书签读取被写成
`if (layout_match && h.bm_count <= ...)`。改字体/字号/行距/边距/字距/缩进/旋转任一项，
`layout_match` 即为假 ⇒ 书签一条都不进内存（`s_bm_count=0`）⇒ 退出阅读器时
`book_save_progress()` 用 0 条整份重写 `.pos` ⇒ **磁盘上的书签被真正抹掉**。
不是显示问题，是丢数据。任何人再改这段，必须先读本节。

## 4 支持格式

TXT（含 GB2312→Unicode）、**EPUB**（`epub_convert`）、**FB2**（`fb2_convert`）。
格式探测细节见各转换器入口。

## 5 已实现的功能（B1–B5 + F2/F5/F7）

| 编号 | 功能 | 实现要点 |
|---|---|---|
| B1 | 底部信息条遮挡正文 | 布局扣除信息条高度；**索引缓存魔数升级**（顺带修掉一个既有 bug）|
| B2 | GBK 标点避头尾 | 补 GBK 断行机会计算（原实现完全不做）|
| B3 | 触摸翻页 | 改为左右分区判定（原实现只判纵向，横坐标被丢弃）|
| B4 | 大文件页表与索引错误处理 | 页表超限有提示 |
| B5 | 进度原子写 + 节流 | 避免频繁写 NVS |
| F2 | 百分比跳转 | 页级精度 |
| F5 | 垂直居中 | 短页居中显示 |
| F7 | 章节导航 | 按 `第X章 / Chapter / Vol` 规则识别 |

**改动集中在** `book_reader.c`（+356/−66）与 `book_flow.c`（+50/−1）；`page_book.c` 未改动。

## 6 内存

页表与大缓冲全部走 `MALLOC_CAP_SPIRAM`（2 MB 页表 + 最多 3 MB realloc 峰值均为**代码推算**，真机空闲量未实测）。

## 7 已知限制（当前仍存在）

| # | 限制 | 说明 |
|---|---|---|
| 1 | 页表上限 | 524288 页 ≈ 226 MB（24px）。超限**有提示**但翻不到后面 |
| 2 | PSRAM 余量未实测 | 上述 2 MB / 3 MB 是推算值 |
| 3 | B2 只覆盖 GBK | UTF-8/UTF-16 仍走 libunibreak；GBK 表不含 ASCII 半角标点 |
| 4 | F2 精度是页级 | 超长单行页可能偏差较大 |
| 5 | F7 依赖规则识别 | TXT 无章节标记时只能按字数兜底分节 |
| 6 | 竖屏未单独验证 | 代码按 `book_is_portrait()` 分支，**无真机确认** |
| 7 | 首页同步索引 48 KB | 打开大书仍有一次同步索引，耗时未测 |
