# 应用资料 · 矢量地图

> 适用：LinTOS 1.0。Lua 应用。
> **开发源：`apps/lua/src/map.lua`**（顶层 local 198 个）；打包产物 `apps/lua/apps/app/map.lua`（200 个）。
> 数据格式：[地图数据格式](../../规范/地图数据格式.md)（`.ltm v3`）。
> 本文只写**当前实现**；历史过程已归并于此，原报告已清理。

## 1 用途

离线矢量地图：下载地图包、平移缩放、图层开关、查看路网/水系/POI、记录与显示 GPX 轨迹。

## 2 源码与资源

| 项 | 值 |
|---|---|
| 开发源 | `apps/lua/src/map.lua`（**唯一开发源**，改这里）|
| 打包产物 | `apps/lua/apps/app/map.lua`（由构建流程生成）|
| 地图包 | TF 卡上的 `.ltm` 文件 + 包内文件表 |
| 轨迹 | GPX 文件 |
| 图层选择 | NVS `lay` 键 |

**约束**：四项新功能实现时**顶层 local 一个没加**（198 → 打包 200），避免注册表膨胀。

## 3 架构

```
on_enter  → 扫包目录 → files[] 索引 → 载入 .ltm 头与图层索引
render    → 三层绘制（底图 → 路网/水系 → POI/轨迹），折线走 app.poly 批量提交
下载       → fetch_start → poll 轮询进度 → 分块写 .bin → 校验 → 合并进索引
轨迹       → 记录/回放/大文件护栏
```

## 4 已实现功能

| 编号 | 功能 | 要点 |
|---|---|---|
| **B3** | 地图包管理增强 | **换包失败回滚**、**删当前包拒绝**、**按精确路径删除**（不是前缀匹配）|
| **B9** | 轨迹大文件护栏 | 防止一次读入超大 GPX |

> 代码里还有 `B2` / `B10` 等编号注释，但**没有对应的功能说明**，语义以 `src/map.lua` 为准 ——
> 不要根据编号反推功能。

## 5 依赖与限制

| 项 | 限制 |
|---|---|
| `app.fs.read` | ≤512 KB；大文件必须 `read_at`（≤1 MB/次）|
| `app.net.http_get` | 只支持 HTTP、≤4 KB —— 下载大包**必须用 `app.net.fetch_*`** |
| Lua 数字 | `LUA_32BITS` ⇒ float 约 7 位有效；**坐标用整数微度，先减后乘** |
| 图片 | 1bpp BMP，单张 ≤4 MB、宽 ≤2048、`blit` 宽 ≤512 |
| `app.fs.remove` | FATFS 上的真实返回与残留未在真机确认 |

## 6 已知问题（源码可验证，未修复）

| 编号 | 问题 | 后果 | 证据 |
|---|---|---|---|
| **R1** | `files[]` 只处理前 **30** 条（`pick` 取 40）；`scan_pkgs` 只扫目录前 **24** 个条目 | 包/文件多了会**静默漏掉** | 源码行号已漂移，按函数名定位：`pick` / `scan_pkgs` |
| **R2** | 下载中退出只取走在途请求，**不删半包** | 半个 `.bin` 留在 TF；下次覆盖前若被扫到可能读到损坏包 | 同上 |

## 7 验证状态（重要）

| 项 | 状态 |
|---|---|
| 静态检查 `lua_check` | ✅ 全绿 |
| 真实 Lua 5.5 编译/运行（桌面）| ✅ |
| 模拟器实测 | ✅（换包回滚、删当前包拒绝、精确删除、轨迹护栏）|
| **真机** | **❌ 未验证** |

未验证事项：

1. 真机触摸手感、长按 700 ms 阈值是否合适。
2. SD 读速对"打开轨迹列表 80 KB"的影响。
3. 真机 FPS / 单帧耗时（B3 增加绘制量是否可忽略）。
4. `app.fs.remove` 在 FATFS 的真实返回与残留。
5. NVS `lay` 键的断电保持。
6. 精度圈 5.0 系数与实际定位误差的吻合度。
7. **打包产物在设备 Lua 上的编译** —— 模拟器是桌面 lua55，`LUA_32BITS` 可能不同，整数/浮点行为需真机确认。

## 8 怎么验证

```bash
python3 tools/lua_check.py apps/lua/src/map.lua    # 静态检查（改开发源）
python3 tools/lua_sim.py  apps/lua/src/map.lua     # 主机模拟
```

真机：放一个 `.ltm` 包 → 打开 → 平移/缩放 → 断网重开（应可用）→ 下载中途退出（查 TF 是否留半包）→ 记录轨迹。
