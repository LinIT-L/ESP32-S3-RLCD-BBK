# 应用资料 · 录音机

> 适用：LinTOS 1.0。Lua 应用（单文件）。
> 源码：`apps/lua/apps/app/recorder.lua`（**1215 行**）。
> 本文只写**当前实现**；历史过程已归并于此，原报告已清理。

## 1 用途

麦克风录音存 TF 卡为 **WAV**，可回放、改名、删除。
LAPP 头：`name=录音机 cat=软件 desc=麦克风录音存 TF 卡 (WAV), 可回放、改名、删除`。

## 2 源码与目录

| 项 | 值 |
|---|---|
| 文件 | `apps/lua/apps/app/recorder.lua` |
| 分类 | 软件 |
| 格式 | WAV，默认 16000 Hz |
| 存储 | TF 卡（具体目录见 `on_enter` 的路径常量）|

## 3 架构

```
on_enter → app.rec.mic_available() 判断有无麦 → 扫录音目录
render   → 峰值（rec.peak）+ 计时（rec.ms）+ 频谱（rec.spec）+ 列表
poll     → 录音中轮询 ms/bytes/peak；播放中轮询 play_ms
action   → 开始/停止录音、选中、改名、删除
on_exit  → 停止录音/播放，释放
```

**录音是异步的**：`app.rec.start()` 立即返回，底层独立任务（CPU1）写盘；进度只能轮询。

## 4 API 契约

| API | 返回 | 注意 |
|---|---|---|
| `app.rec.mic_available()` | bool | **进页面先问**，无麦要给提示 |
| `app.rec.start(path[, rate])` | 0 成功 / <0 失败 | -1 已在录 / -2 麦失败 / -3 建不了文件 / -4 建不了任务 |
| `app.rec.stop()` | 已录 ms | 底层异步收尾写 WAV 头 |
| `app.rec.active()` / `ms()` / `bytes()` / `peak()` | — | `bytes` 判"卡住"；**`peak` 是全程峰值，只增不减，不能当实时电平表** |
| `app.rec.spec(bin)` | 0..100 | **实时 16 段频谱**，bin 从 1 起 —— 实时电平该用它 |
| `app.rec.play(path)` | 0 成功 | 只播 **WAV**；-1 上一段没停 / -4 已静音 |
| `app.rec.mplay(path)` | int | 播任意音频（`audio_player_play`）|
| `app.rec.stop_play()` / `mstop()` | — | 停止 |
| `app.rec.playing()` / `mplaying()` / `play_ms()` / `play_total_ms()` | — | 墙钟推进 |

## 5 硬件依赖

| 项 | 说明 |
|---|---|
| 麦克风 | 小智（ES7210）/ 微雪（板载）**有**；**标准扩展版无麦克风**（`i2s_din = -1`）|
| 存储 | TF 卡；未挂载时录音应被拒绝 |
| 输出 | I2S + 功放（GPIO46 低有效）|

> 标准扩展版上本应用**不可用**，是硬件限制，不是 bug。

## 6 未实现的功能与底层限制（**重要，别当 bug 修**）

| 功能 | 状态 | 根因 |
|---|---|---|
| 播放暂停/继续 | ❌ 未实现 | `audio_player` 的 WAV 路径没有 pause/resume，只有 `play_wav` / `wav_stop`。界面**不放**假按钮 |
| 播放 seek | ❌ 未实现 | `audio_player_seek_to()` 只对 MP3 有效，WAV 任务不读 |
| 播放变速 | ❌ 未实现 | 无接口 |
| 修 `data_len=0` 的坏文件 | ❌ 未实现 | `fs.write` 是 `wb` 会清空文件；`fs.read` 上限 512KB（≈8 秒音频）→ 无法安全重写头。只能检出+提示 |
| 剩余容量显示 | ❌ 未实现 | `app.fs` 无 statfs，只能靠写失败发现卡满 |
| 文件锁定（防误删）| ❌ 未实现 | `app.nvs` 键名 ≤15 字符，存不下多个文件名；换卡后语义失效。做成内存态等于假功能，故不做 |
| 列表跟手滚动 | ❌ 未实现 | Lua 桥无 `ui_scroll` 封装，只能分页（一次 3 行）|
| 实时电平表 | ⚠ 部分 | `rec.peak()` 是全程峰值；实时请看 `rec.spec()` |

## 7 已知问题

- 改名/删除的确认流程是否覆盖所有路径（如录音中删除当前文件）**待核实**。
- 录音时直接退出应用，文件头是否正确收尾**待上机确认**。

## 8 怎么验证

```bash
python3 tools/lua_check.py apps/lua/apps/app/recorder.lua
python3 tools/lua_sim.py apps/lua/apps/app/recorder.lua
```

人工：录 10 秒 → 停止 → 列表出现 → 回放（能听到）→ 改名 → 删除 → 重进（列表已更新）。
**录音中退出**后把文件拷到 PC，确认能被播放器打开（文件头收尾正确）。
