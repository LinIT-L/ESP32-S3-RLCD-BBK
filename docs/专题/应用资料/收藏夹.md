# 应用资料 · 收藏夹

> 适用：LinTOS 1.0。C 内置应用。
> 源码：`components/apps/pages/page_fav.c`（页面与数据）、`components/apps/pages/fav_web_page.h`（网页端）、
> `components/services/favorites/favorites.c`（存储服务，234 行）。
> 本文只写**当前实现**；历史过程已归并于此，原报告已清理。

## 1 用途

跨引擎收藏：把游戏、文件、网页路径存成一条记录，带分类，可导入/导出备份，有独立 PIN 门禁。

## 2 入口与源码

| 项 | 值 |
|---|---|
| 页面 | `components/apps/pages/page_fav.c` |
| 网页端 | `components/apps/pages/fav_web_page.h`（设备起 HTTP 服务，PC/手机管理）|
| 存储服务 | `components/services/favorites/favorites.c` |
| 门禁 | `applock_gate()`，收藏夹有独立 PIN 槽 |
| 容量 | `FAV_MAX = 256` 条 |

## 3 数据模型（NVS 命名空间 `linfav`）

| 键 | 内容 |
|---|---|
| `blob` | 条目主体（图标 + 名称 + 路径 + 分类）|
| `enc` | **账号/密码段，单独加密**（AES-256-GCM，密钥来自 `applock`）|
| `pinsset` | 是否已设 PIN |
| `pinblob` | PIN 校验数据 |
| `categories` | 分类定义 |

- 密码段缓冲 `s_encbuf` 为 **24 KB 静态**，约 438 组账密封顶；超了整次保存失败（有 `ESP_LOGE` + toast）。
- 加密不自己实现，密钥全部走 `applock`。

## 4 核心流程

```
进入 → applock_gate("fav") → fav_load() 读 NVS → 分类栏 + 条目列表
点条目 → 按类型分发（引擎 / 文件 / 网页 / 账号）
编辑/删除 → fav_save() 写回 → fav_exit() 落盘
导入/导出 → 加密备份文件（FAVEXP3 格式）
```

## 6 已知缺陷（**当前仍存在，未修**）

### P0

| # | 问题 | 后果 |
|---|---|---|
| **P0-1** | **导入备份后 RAM 里的密码被清空**；此后任意一次 `fav_save()` 会把 NVS 的密码密文整体覆盖成空 | **密码永久丢失** |

> 位置：`fav_load` 无条件清零结构体 → `pw_touch` / `fav_pick_import_cb` 未回填 → `fav_save` 落盘。

### P1

| # | 问题 |
|---|---|
| P1-1 | 密码仍通过 **URL query** 传输（`/api/cred?op=add&p=<明文>`）|
| P1-2 | 导入时把完整明文写成 `<备份>.dec.tmp` 落盘；若备份在老位置 `/sdcard/fav.bak`，该明文文件**永不清理** |
| P1-3 | `blob` 与 `enc` 两次独立写，且 **`nvs_commit` 在 IDF 6.0 是 no-op** → 掉电可致"新条目 + 旧密文"错配，密码串到别的账号 |
| P1-4 | `fav_save()` 不检查 `svc_nvs_set_blob` 返回值 → NVS 满时**静默失败**，UI 无提示 |
| P1-5 | 导出先 `remove` 再 `rename`：rename 失败 = 旧备份已删 |
| P1-6 | 备份口令最小 4 位，PBKDF2 20000 次，GPU 秒破 |
| P1-7 | `editCred()` 取密码失败时**无限递归** → 请求风暴 |

## 7 已知限制（设计取舍，非缺陷）

| # | 限制 | 说明 |
|---|---|---|
| 1 | NVS 不是真事务 | 掉电撕裂靠 seq 校验**拒绝解密并提示**，不自动恢复。双槽要占 240KB/256KB 分区，需改存储布局 |
| 2 | 备份条目数为 `u8` | 最多 255 条，第 256 条不导出。改格式要升 `FAVEXP3` 且保留旧格式解析 |
| 3 | 密码段 24 KB 上限 | 约 438 组；提高要占内部 RAM |
| 4 | HID 只支持 US 键盘布局 | UK/DE/FR 主机会打出别的字符（有一次性提示）|
| 5 | 旧 NVS 图标未清理 | 迁移后仍占 32KB，只靠标记不再读取（保留便于回退）|
| 6 | 历史 `.dec.tmp` 物理残留 | 目录项可删，FAT 簇内容需格式化或覆盖写 |
| 7 | 主机侧单元测试未做 | 宿主编译器被 Xcode license 拦住 |
