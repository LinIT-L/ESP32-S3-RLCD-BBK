# 板型 IO 表

| 项 | ①小智 | ②微雪原版 | ③微雪自定义 PCB |
|---|---|---|---|
| LCD DC/CS/SCK/MOSI/RST | 7/11/9/10/不接 | 5/40/11/12/41 | 同② |
| LCD SPI 时钟 | 60M | 60M | 60M |
| 触摸 SDA/SCL/INT/RST | 5/13/12/6 | 无 | 15/7/17/2 |
| 按键 PWR/RIGHT/确认 | 1/0/4 | 18/0/18 | 1/0/1 |
| 电池检测 | GPIO3 / CH2 | GPIO4 / CH3 | 同② |
| I2S MCLK/BCLK/WS | 40/39/45 | 16/9/45 | 无/9/45 |
| I2S DOUT/DIN | 48/21 | 8/10 | 8/无 |
| codec I2C SDA/SCL | 38/47 | 13/14 | — |
| 功放使能 | 46 | 46 | 46 |
| 震动 PWM | 8 | 48 | 48 |
| SD CLK/CMD/D0 | 16/15/17 | 38/21/39 | 同② |
| GPS TX/RX/EXTINT | 43/44/18 | 43/44/47 | 43/44/47 |

**③ 相对 ②**：触摸新增、按键改 1/0/1、音频换 NS4168（无 MCLK、无录音），其余同②。

**三条不能错**：确认键 ①4 / ②18｜**8 与 48 两板对调**（①震动8·DOUT48，②③震动48·DOUT8）｜① 的 LCD RST 不接 ⇒ 驱动 `(1ULL<<rst)` 必须 `>=0` 保护。

**换板**：改 `board_pins.h` 选板宏 → `PYTHONPATH= ./build.sh` → 整片 16MB 烧 `dist/merged_16mb.bin`。
