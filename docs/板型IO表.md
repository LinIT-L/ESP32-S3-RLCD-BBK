## 换板怎么做

1. **直接换板、开机即可** —— 开机 `hw_cfg_init()` 探 I2C 指纹自动定板型，**不用重编、不用进设置选板**。
2. 探不到（自己改线 / 换了芯片）→ 设置 → 网络与系统 → 硬件管理 → **重新自检**；
   仍失败则沿用 NVS 里上次成功的板型（不会变砖）。
3. 三块板共用 `dist/LinTOS_16mb.bin`，只维护这一个固件；换板不需要 `BOARD_IS_WEIXUE` 改 0/1。

## 不能撞的脚

- **8 / 48 两板对调**：① 震动 8 + I2S DOUT 48；②③ 震动 48 + I2S DOUT 8。
- **GPIO40 双义**：②③ 是 LCD CS，① 是 I2S MCLK。
- **① 屏 RST 不接** ⇒ 驱动里 `(1ULL << rst)` 必须带 `>= 0` 保护，否则 abort ⇒ 重启循环。
- **② 微雪的 PWR 不是 GPIO**：板载三个物理键里，PWR 接的是电源锁存 IC（U3 / ECJ23001），
  长按=直接断电、单击=开机，**固件读不到也不用管**；能读的只有 BOOT(0) 与 KEY(18)。
  表里 `btn_pwr` 填 18 只是为了**深睡 EXT1 唤醒与唤醒门控**（EXT1 只能挂可读的引脚），
  `input` 检测到与 KEY 同脚会自动禁用"固件电源键"语义 ⇒ 微雪不会误投"锁屏/2s 关机"。
  ⚠ 想给微雪加"固件侧关机"只能另配组合键（单键已被确认/蓝牙搜索占满）。
- **① 电源 1 / 返回 0 / 确认 4**、**③ 电源 1 / 返回 0 / 确认 18** 都是三脚独立，固件可正常长按 2s 关机。
- ⛔ 改任何引脚前先全工程搜"这个号还有谁在用" —— 撞脚后的现象与元凶通常毫无关系
  （EXTINT 设成 8 ⇒ 一直震；MCLK 设成 40 ⇒ 微雪全黑）。
