## 1. 蓝牙搜索流程（进入必显示"正在扫描…"，返回即重扫）

**问题**（串口核实）：一进搜索就"未发现设备"——`esp_hid_scan()` 开头检查全局旧结果非空即返回 `ESP_FAIL`，扫描根本没真正开始；返回不重扫；扫描状态无终结感误报。

**目标交互**：进入立即显示"正在扫描…"持续一个周期(约3~5s)，实时刷新；结束有设备则列表连接、无设备显示"未发现"且确认/返回=重新扫描；扫描中返回=停本次并自动重扫；扫描中确认=忽略。

**改动**：
1. `bt_ctl/esp_hid_gap.c esp_hid_scan()` 开头清理全局旧结果（`esp_hid_scan_results_free`+置0），不再返回 ESP_FAIL —— 核心修复。
2. `bt_core.c scan_task` 兼容清缓存，确保每次真起扫。
3. `page_gamepad.c open_scan_dialog` 进入 `s_scan_n=0`、显示"正在扫描…"。
4. `scan_dlg_poll` 用阶段状态机 `SCANNING→DONE`（收 on_scan_done 才转 DONE），避免扫描中误报。
5. `scan_dlg_key`：BACK/无设备按确认 → `stop_scan` 后立即 `start_scan_continuous` 重扫并清空列表回 SCANNING。

边界：连续扫描去重（`bt_core_scan` 有 `if(s_scanning)return`）；扫描放后台不阻塞 UI；ACE 仅 BLE，不搞经典蓝牙。

**验证**：首次长按确认键 → "正在扫描…"持续3~5s 不秒失败；有设备可连；无设备按确认/返回重扫；进出5次无任务堆积。

## 2. 科学计算器移植（已实现为 page_calculator）

**功能**：四则 `+-*/`、幂`^`、取余`%`、阶乘`!`、括号、隐式乘法(`2π`,`3(4)`)；科学 `sin/cos/tan/asin/acos/atan`、`sinh/cosh/tanh`、`ln/log/log2`、`sqrt/exp/abs/floor/ceil`；常量 `π/e`、上一结果 `Ans`、角度/弧度切换；自动科学计数、错误提示；触摸虚拟键盘+手柄导航（复用 `km_draw_cell`）。

**方案**：表达式引擎增量自研（词法→shunting-yard→后缀，double）或 TinyExpr（单文件、zlib、零依赖，倾向）；UI 新建 `page_calculator.c`；注册进 os_pages；图标 64×64 RGBA→1bpp 入 `icons_main.inc`。

**规模**：引擎 .text 6~9KB + 页面 7~11KB ≈ 新增 15~25KB Flash，RAM 峰值 <1KB 栈+PSRAM 缓冲，空间无压力。

**风险**：运算符字形可能缺字 → 用 ASCII `* / sqrt ^ !` 拼写或补点阵字符；图标二值化阈值需目视；角度/Ans/报错文案定稿；真机验证。

## 3. 阅读器功能增强（规划稿）

**设备约束**：黑白 400×300，可 4 向旋转；设置项统一「滚轮列表菜单」；书本在 `/sdcard/books`、字体 `/sdcard/fonts`。

**目录生成**：扫描逐行匹配章节规则（优先级依次）——
- A `第[数字|中文数字|大写][章章节卷回话部篇]`
- B 特殊章名（序章/楔子/正文/终章/后记/尾声/番外/前言/简介）
- C 数字+分隔符+标题（`1、` `一、` `(12)` `【第一章】`）
- D 英文 Chapter/Part/No./Episode
- E 书名+纯数字行
- F 兜底按字数(5000)分节
只匹配行首（`^`锚定）；章节名≤30字；目录两级(卷→章)。参考 Legado `txtTocRule.json`。

**字体**：内置仿宋/黑体 + TF卡 `/sdcard/fonts/*.fnt|bin`(≤16) + 字号 20/24/28/32；字体走列表弹窗、字号走滚轮。

**排版**：分页后台重排、前台渲染当前页；中文断行 libunibreak；段落首行缩进两全角空格(可关)、两端对齐；夜间=反色；竖屏 300×400 逻辑缓冲整帧旋转；进度每5页保存断点。

**滚轮横竖适配**：组件化 `wheel_list`，横屏=竖长方形(上下滚)、竖屏旋转成横长方形(左右滚)；方向轴随旋转切换、触摸坐标由 input 层旋转映射。

**设置项(滚轮)**：字号/字体/行高/边距/字距/段落缩进/夜间/页码/旋转。

**实现顺序**：修TF卡 → 旋转验证 → 滚轮组件化 → 章节解析 → 排版优化 → 夜间/进度/TF字体/多格式回归。

## 4. 阅读器重构（V2）

**目标**：解决「打开卡顿/死机、旋转方向不一致、目录识别错乱、字体切换与滚动不跟手」。

**架构**：拆职责单一模块（`book_reader/`）：
`book_reader.h`(对外API稳定) + `br_core`(阅读会话状态机) + `br_index`(页偏移表PSRAM静态+后台任务+断点续扫+侧边.idx) + `br_toc`(目录识别+兜底分节) + `br_font`(字体/字号/行距/边距) + `br_rotate`(单一旋转源) + `br_render`(排版绘制) + `br_menu`(超长窗口) + `br_setting`(NVS)；`book_flow`/`font_book`保留只读依赖。

**关键决策**：
- **旋转**：一份旋转值存NVS `rt`(0/1/2/3)，书架/阅读/触摸共用一套坐标映射；打开时 `input_set_screen_rotation`，退出设0。
- **目录**：数字匹配按 **UTF-8 三字节码**(一=E4B880，杜绝旧 Unicode码点误用)；标题去首缩进、截断31字节；预扫描后台逐行+每2块 `vTaskDelay(1)` 即时渐进填充；反证排除(分部/第X无后缀)；`.idx` 版本 06→09 强制重建。
- **瞬间打开**：主线程零同步索引(打开+嗅探编码+静态PSRAM缓冲+载入页表/进度即返回)；后台 `br_index` 断点续扫(256KB/步+5ms+喂WDT)；未索引页渲染等待有界≤800ms。
- **菜单超长窗口**：`br_menu` 像素级跟手(`s_menu_pix`)+Windows式右侧滚动条(可拖)+拖动松手抑制跳转。

**回归清单**：秒进不卡、快速翻页100+不卡死、旋转2/3方向一致、目录≈2346章无噪声、切换字号/字体即时重排断点不错、退出重开秒恢复。

## 5. TF卡挂载/卸载串口切换崩溃（✅ 已彻底解决 2026-08-29）

**结论**：采用「按需切换 + 纯MSC + 挂载期暂停串口控制台 + 看门狗时限调大」。

两层问题：
1. **挂载时崩溃/无限重启**（历史遗留）：副控制台挂 USB Serial/JTAG，卸载驱动后仍写日志 → 崩溃。`sdkconfig` 中 `CONFIG_ESP_CONSOLE_SECONDARY_USB_SERIAL_JTAG=1` 为元凶。修法：按需切换——正常=USB Serial/JTAG 控制台(不装TinyUSB)；挂载=切纯MSC U盘(`esp_tinyusb v2.2.1`)；挂载期 `log_console_suspend(true)` 暂停串口控制台(日志只写 `/sdcard/log/bbk.log`)。
2. **卸载时重启**：`sd_scan` 的 6 秒看门狗误伤（卸载链耗时>6s 被 `esp_restart()`）。修法：不要把看门狗永久关，把时限从 6000 调到 15000~20000ms。

**关键文件**：`usb_hid/usb_hid.c`(按需切换 enter_msc/enter_hid/exit)、`usbh_msc/usbh_msc_sdspi.c`(纯MSC挂载)、`main/main.c log_console_suspend`、`sd_scan/sd_scan.c`(看门狗时限)、`page_storage.c`(挂载/卸载任务)。

**恢复**：若再陷入无限重启且 USB 串口消失，先进下载模式(BOOT+RST)让 `/dev/cu.usbmodem*` 重现，再烧稳定固件 `dist/merged_16mb.bin`。
