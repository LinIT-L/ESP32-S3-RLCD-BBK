# 阅读器（小说阅读）功能增强计划书

> 版本：v0.1（规划稿）
> 设备：黑白屏 400×300（ST7305，1bit），可 4 向旋转（上/下/左/右）
> 参考：本地已下载的开源项目 `reference/legado`（章节解析/排版）、`reference/koreader`（嵌入式排版）、`reference/koodo-reader`（阅读 UI）

---

## 1. 概述与设备约束

| 约束 | 说明 |
|---|---|
| 屏幕 | 黑白 1bit，400×300 横屏原生；竖屏用 300×400 逻辑缓冲 + 软件旋转 |
| 旋转 | 上(0°) / 下(180°) / 左(90°) / 右(270°)，触摸坐标须同步旋转 |
| 交互 | 触摸 + 手柄；所有设置项统一用「滚轮列表菜单」（参考设置页日期/时间滚轮） |
| 存储 | 书本在 TF 卡 `/sdcard/books`，字体在 `/sdcard/fonts` |
| 性能 | 双核 ESP32-S3，黑白渲染快；重排（分页）放后台任务，前台滚动流畅 |

## 2. 目录（TOC）生成方案

> 参考 Legado `txtTocRule.json`（25 种规则），本项目只需精选若干高频规则，在扫描书籍时逐行匹配，命中行即作为章节起点。章节标题存入 `s_chapters[]`，进入阅读器可跳转。

### 2.1 规则集（按优先级依次尝试，任一命中即认定章节行）

**规则 A：中文"第X章/节/卷/回/话"（最常用）**
- 匹配：`第` +（阿拉伯数字 | 中文数字 `〇零一二两三四五六七八九十百千万` | 大写 `壹贰叁肆伍陆柒捌玖拾佰仟`）+（`章`|`节`|`卷`|`回`|`话`|`部`|`篇`）
- 示例：`第一章 标准格式` / `第3章 无标题` / `第一百二十章 高潮`

**规则 B：特殊章节名（独立行）**
- `序章` `楔子` `正文` `终章` `后记` `尾声` `番外` `前言` `简介`

**规则 C：数字/中文数字 + 分隔符 + 标题**
- `1、标题` `1.标题` `一、标题` `24章 标题` `(12)标题` `【第一章 标题】`

**规则 D：英文章节**
- `Chapter 1 xxxx` / `Part 1 xxxx` / `No.1 xxxx` / `Episode 1 xxxx`

**规则 E：书名+序号（纯数字行）**
- `标题(12)` / `标题124`（行内仅书名+数字）

**规则 F：兜底——字数分节**
- 无任何规则命中时，按固定字数（默认 5000 字）自动分节，保证有目录可跳。

### 2.2 实现要点
- 扫描时**逐行读入缓存**（`book_scan_chunk` 现有机制），对每行做 UTF-8/GBK 统一解码后匹配。
- 只保留**行首规则**（`^` 锚定），避免正文中间句子误判。
- 章节号可含**卷**（如 `卷五`），目录支持两级（卷→章）。
- 目录项上限：保持 `s_chapters` 现容量（约几百章足够）。
- 章节名最多取 30 字（Legado 同款 `.{0,30}`）。

## 3. 字体更换

| 字体来源 | 说明 |
|---|---|
| 内置仿宋 | `font_book_select(0, size)` |
| 内置黑体 | `font_book_select(1, size)` |
| TF 卡字体 | 扫描 `/sdcard/fonts/*.fnt|*.bin`（现有 `font_book_scan_sd`），最多 16 个 |
| 字号 | 20 / 24 / 28 / 32（现有 `s_fontsize`，4 档） |

- 字体内置加载失败时回退仿宋。
- TF 字体选择走「列表弹窗」（现有 `bs_font_dlg`），字号走「滚轮」。

## 4. 阅读格式

| 格式 | 现状 | 规划 |
|---|---|---|
| TXT | 支持（GBK/UTF-8/UTF-16LE/BE 自动识别） | 增强章节解析（见 §2） |

## 5. 设置项（统一滚轮列表菜单）

所有设置项用**滚轮列表**（上下滚动选择，参考设置页日期/时间滚轮）。旋转后滚轮自适应横竖（见 §7）。

| 设置项 | 取值（滚轮档位） | 说明 |
|---|---|---|
| 字号 | 20 / 24 / 28 / 32 | 调小字号→每页更多字 |
| 字体 | 仿宋 / 黑体 / TF字库… | 滚轮循环选择 |
| 行高 | 紧凑 / 标准 / 宽松 | 参考 Legado `lineSpacingExtra` |
| 边距 | 窄 / 中 / 宽 | 参考 Legado `paddingLeft/Right` |
| 字距 | 标准 / 宽松 | 参考 Legado `letterSpacing` |
| 段落缩进 | 开 / 关 | 开=每段首行两全角空格（`　　`，Legado 同款） |
| 夜间模式 | 开 / 关 | 黑白屏=反色（黑底白字 ↔ 白底黑字） |
| 显示页码 | 开 / 关 | 页脚 `当前页/总页` |
| 旋转方向 | 上 / 下 / 左 / 右 | 循环切换，立即生效并记忆 |

> 各档位**循环滚动**（到头回绕），拖动手感与游戏菜单右栏一致。

## 6. 阅读排版

- **分页**：按当前字号/行高/边距/字距计算每页可容纳行数与每行字数（`bf_layout` 现有），后台任务重新分页（`book_restart_index`），前台只渲染当前页窗口。
- **中文断行**：沿用 libunibreak（中英混排不断错词）。
- **段落**：首行缩进两全角空格（可关）；段间距按行高档位（参考 Legado `paragraphSpacing`）。
- **对齐**：正文两端对齐（中文），标题居中，页码右对齐。
- **黑白渲染**：
  - 普通：白底黑字。
  - 夜间：黑底白字（`st7305_set_inversion` 已实现）。
- **竖屏（左/右）**：300×400 逻辑缓冲绘制（含菜单/页码/退出框），整帧软件旋转回横屏输出（`portrait_rotate` 已实现）。
- **进度**：每 5 页自动保存（现有），支持断点续读 + 章节/页码双定位。

## 7. 滚轮列表菜单的横竖适配（关键交互）

> 需求：设置项用"修改时间"同款滚轮；因阅读会旋转，旋转后滚轮要"左右缩变成长方形"。

### 7.1 现状
设置页的日期/时间滚轮是**竖长条**（高 250 × 宽 350 弹窗内，竖向滚轮、上下滚动）。

### 7.2 规划：滚轮组件化，双布局
新增**可旋转滚轮组件** `wheel_list`：
- **横屏布局（旋转 上/下，屏幕 400×300）**：滚轮为**竖向长方形**（左右窄、上下高），上下滚动选择。
- **竖屏布局（旋转 左/右，逻辑 300×400）**：滚轮整体旋转，变**横向长方形**（左右宽、上下矮），**左右滚动选择**（方向轴随旋转切换，触摸坐标已由 input 层旋转映射）。

```
横屏(上/下)          竖屏(左/右)
┌──────┐            ┌──────────────┐
│  28   │            │  24  28  [32]  │  ← 横向长方形，左右滚动
│ [24]  │            └──────────────┘
│  20   │
└──────┘
```

### 7.3 实现要点
- 滚轮组件的**选中行高亮**、**滚动跟手**、**首尾循环**逻辑复用设置页滚轮。
- 布局几何由 `book_is_portrait()` 决定：横屏用竖条，竖屏用横条。
- 旋转方向切换时，滚轮立即重排为新布局（与阅读页正文同步旋转）。

## 8. 与阅读器菜单的关系（"菜单放桌面"）

- **阅读设置**（字号/字体/行高/边距/字距/段落缩进/夜间/页码/旋转）统一放**书架页的「阅读优化」**（桌面可达，现已在 page_book），用滚轮列表呈现。
- 阅读器内保留：**目录 / 书签 / 字体 / 旋转方向 / 返回书库 / 继续阅读** 短菜单（跟随旋转），便于阅读中快速操作。
- 两处共用同一 NVS 设置（现有 `os_book` 命名空间），改动互相生效。

## 9. 实现顺序

1. **修 TF 卡**（前提）：chkdsk/急救修复 FAT，或格式化重拷（解决 size=0/漏书/缺字体）。
2. **旋转修复验证**：实机确认 4 向旋转 + 菜单关闭（已改，待卡修好验证）。
3. **滚轮组件化**：`wheel_list` 横竖双布局，接入阅读设置。
4. **章节解析增强**：按 §2 规则集实现目录生成（参考 Legado 规则）。
5. **排版优化**：段落缩进、两端对齐、卷章两级目录。
6. **体验收尾**：夜间反色、进度保存、TF 字体、多格式回归。
