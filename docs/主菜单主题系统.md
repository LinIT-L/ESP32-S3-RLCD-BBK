# 主菜单主题系统（os_theme）

> 结论先说：**"主菜单抽成模块 + 主题化"这个地基已经存在**（`os_theme.c` + `page_main.c` 全部走主题钩子），
> 2026-09-22 补齐了它缺的三件：**多主题 / 选择入口 / 持久化**；"下载主题"仍留作后续。

## 一、接缝在哪（改一个框架，整体跟着变）

| 层 | 位置 | 说明 |
|---|---|---|
| 主题定义 | `components/system/os/include/os_theme.h` | `os_theme_t`：布局参数 + 3 个视觉钩子 |
| 主题表/选择/落盘 | `components/system/os/kernel/os_theme.c` | 内置主题、`os_theme_set/get/load/save` |
| 渲染（读主题） | `components/apps/pages/page_main.c` | 背景/图标/标签/间距全从 `os_theme_get()` 取 |
| **命中（必须同源）** | `page_main.c` 的 `p_main_touch()` / `p_main_poll()` | 原先把 `100.0f`/`屏高/2±50/70` **写死** → 已改为读主题（否则换主题就点不准） |
| 设置入口 | `page_settings.c` →「显示与时间」→「菜单主题」 | 选中即生效 + `os_theme_save()` + toast |

参数：`icon_spacing`(格距) · `icon_center_y`(图标中心 y) · `icon_center`(中央尺寸) ·
`icon_normal`(两侧尺寸) · `label_dy`(标签下移) · `bg_color` · `draw_bg/draw_icon/draw_label`(钩子，NULL=默认实现)。

## 二、内置主题（**当前只有 1 个：默认**）

| 主题 | 格距 | 中央 | 两侧 | 标签 | 说明 |
|---|---|---|---|---|---|
| **默认** | 100 | 100 | 64 | +68 | ⚠ **参数与历史视觉逐位相同 = 零回归基线**，改它等于改所有人的观感 |

> **2026-09-22 linit 决定**：先只留"默认"。曾试加过"紧凑/宽松/描边"三个**只调参数**的演示主题，
> 已按要求删除 —— 他要的主题是**完全不同的视觉方案**，不是格距/尺寸的简单缩放，所以不摆凑数项。
> 也正因为如此，「设置 → 显示与时间 → 菜单主题」入口一并撤掉（只剩一项的菜单没意义）。
> 真主题定了之后，设置页按下方注释挂回入口即可（代码位置：`page_settings.c` 的 `open_disp_dlg` 附近）。

**接缝仍然保留**（这是做真主题的前提，不是凑数）：
- `page_main.c` 的渲染/命中/拖动**全部**从 `os_theme_get()` 取几何 —— 换主题时"画"和"点"同步变。
  （原先命中把 `100.0f`、`屏高/2±50/70` 写死，换主题必然点不准，这个 bug 已修。）
- `os_theme_set/get/count/name/load/save` 全部可用：加真主题 = 往 `s_themes[]` 加一项，或运行时注册。

预览（不用烧机）：`python3 tools/theme_preview.py` → 输出到 `~/Desktop/LinTOS_Lua应用/sim_out/theme/`。
它**解析** `os_theme.c` 取参数、读 `icons_main.inc` 的真图标、按 `main_icon_size()`/`main_draw_label()` 的算法渲染，
所以图就是设备上的样子（只差 LCD 抖色）。**主题表里有几个就渲染几个**，改完主题拿它当回归图用。

## 三、持久化

- 命名空间/键：`os_settings` / `menu_theme`（与设置页的 `SET_NS` 同一命名空间，⚠ 别写成 `settings`）。
- 读：**惰性** —— 首次 `os_theme_get()` 时读一次 NVS，因此**不依赖启动顺序**（不用改 boot 流程）。
- 写：设置页选完调 `os_theme_save()`（走 `svc_cfg_set_u8`）。

## 四、后续（现在没做）

1. **加真主题**：在设计定了之后 `s_themes[]` 加项（布局参数 + `draw_bg/draw_icon/draw_label` 钩子），
   设置页把入口挂回来（`open_theme_dlg` 的做法见 `page_settings.c` 里的注释）。
2. **主题注册位（下载主题）**：`s_themes[]` 是 `static const`，运行时加不进去。要"下载主题"得改成
   "静态槽 + 可注册槽"，主题包走 **appdata / apps(SPIFFS) / TF**（纯数据：参数表 + 可选图标位图）。
3. **主题自带图标集**：可以做，但 ⛔ **绝不能改 `main_icons[]` 的顺序** —— 那是 `icon_idx` 的 ABI，
   所有应用注册项都按它取图标，顺序一乱全错。主题只能"覆盖某个 icon_idx 的画法"。
4. 动画型主题（如壁纸那种）：照 `wp_program_render(lcd, prog, now)` 的**枚举 + 渲染回调**做，
   **不要**引入脚本/WASM 运行时（固件没有）。
