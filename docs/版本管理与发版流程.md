## 1. 版本号只有一个来源

```
components/system/os/include/lintos_version.h     ← ★ 唯一来源 (SSoT)
```

```c
#define LINTOS_VERSION_MAJOR   1
#define LINTOS_VERSION_MINOR   7
#define LINTOS_VERSION_PATCH   0
#define LINTOS_VERSION_STR     "1.7.0"
#define LINTOS_VERSION_DATE    "2026-10-02"
#define LINTOS_VERSION_NAME    "双手柄档案表"     /* 本版主题 */
```

⛔ **不要再在别处写死版本字符串。** 历史教训：`page_settings.c` 的「系统信息」里硬编码着
`固件版本:1.3`，而代码注释早已到 V1.7.x —— 设备上显示的版本与实际固件**长期不符**。
现在一律走接口：

| 接口 | 返回 |
|---|---|
| `os_version_str()` | `"1.7.0"` |
| `os_version_date()` | `"2026-10-02"` |
| `os_version_name()` | 本版主题 |
| `os_build_stamp()` | `"2026-10-02 11:00"`（**最近一次 cmake 配置**时刻） |
| `os_git_desc()` | `"v1.7.0"` / `"v1.7.0-3-g88140ce-dirty"` / `"unknown"` |

**三处可见**：开机串口横幅 · 设置→网络与系统→系统信息 · 崩溃日志（`esp_git_desc` 同源）。

## 2. 构建信息怎么进去的

`components/system/os/CMakeLists.txt` 在 **CMake 配置期**：

```cmake
find_program(LINTOS_GIT_EXECUTABLE NAMES git PATHS /opt/homebrew/bin /usr/local/bin /usr/bin)
execute_process(COMMAND ${LINTOS_GIT_EXECUTABLE} describe --tags --always --dirty ...)
string(TIMESTAMP LINTOS_BUILD_STAMP "%Y-%m-%d %H:%M")
target_compile_definitions(${COMPONENT_LIB} PRIVATE
    LINTOS_GIT_DESC="${LINTOS_GIT_DESC}" LINTOS_BUILD_STAMP="${LINTOS_BUILD_STAMP}")
```

⚠ **两个坑**（都已在代码注释里写明）：

1. macOS 上 `/usr/bin/git` 是 Xcode shim，直接跑会报 license 失败 → **必须优先 `/opt/homebrew/bin/git`**。
2. 这两个值是**配置期**取的：**增量编译不会刷新**。要让固件里的 `git=` 变成新 tag，
   得让 cmake 重配一次（`touch components/system/os/CMakeLists.txt` 或改任一 CMakeLists）。

## 3. 发版流程（4 步）

```bash
# ① 改版本号（唯一来源）+ 写 CHANGELOG 顶部一节 `## vX.Y.Z (日期)`
vim components/system/os/include/lintos_version.h
vim CHANGELOG.md

# ② 自检：版本号 ↔ CHANGELOG ↔ 已存在的 tag 是否一致
python3 tools/version_check.py

# ③ 构建（走 broker 中和环境，见技能 esp-idf-workbuddy-build-flash）
python3 $IDF_PATH/tools/idf.py build      # 确认 0 error
touch components/system/os/CMakeLists.txt && python3 $IDF_PATH/tools/idf.py build   # 刷新 git 描述

# ④ 提交 + 打 tag（tag 名必须是 vX.Y.Z，与 version.h 一致）
git add -A && git commit -m "feat(vX.Y.Z): ..."
git tag -a vX.Y.Z -m "LinTOS vX.Y.Z — 一句话主题"
```

出整片镜像：`bash merge_flash.sh`（产物在 `dist/`）。

## 5. 回滚手册（本次入库带来的收益）

```bash
git describe --tags --dirty                 # 当前是哪版（-dirty = 有未提交改动）
git log --oneline -20                       # 看历史
git show v1.7.0 --stat                      # 看某版的全部改动
git diff v1.7.0 -- components/engines/      # 与某版比差异

# 只找回某个被删的文件 / 函数
git checkout v1.7.0 -- path/to/file.c       # 从 tag 取回单个文件
git log -p -S 'nd_snif_rx'                  # 按"符号出现/消失"查历史

# 整块回退（危险，确认后再做）
git reset --hard v1.7.0
```

⛔ **不要再裸用 `git clean -fd`**：本次入库前，它会把整个重构成果当"未跟踪文件"删掉。
