## 维护

- 改 / 增 / 删文档：同步本页，全库不留死链与失效章节号。
- 唯一权威：API → 生成文档 · 引脚 → `board_pins.c` · 版本 → `lintos_version.h` · 分区 → `partitions.csv`。
- 新增 Lua API 必须重跑 `python3 tools/lua_api_doc.py`（构建守卫会拦）。
- 过程记录不落盘；结论进手册或 `LESSONS.md`。死链体检：`python3 tools/doc_audit.py`。
