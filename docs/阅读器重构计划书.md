# 电子书阅读器重构计划书（V2）

> **目标**：重构现有阅读器模块，彻底解决「打开卡顿/死机、旋转方向不一致、目录识别错乱、字体切换与滚动不跟手」等历史问题，做到「瞬间进入、跟手拖动、目录正确、旋转统一」。
>
> **架构**：把阅读器拆成职责单一的小模块（布局/渲染、目录、索引、字体、旋转、设置菜单），每个模块状态自洽、与全局旋转解耦。排版内核沿用 `book_flow + libunibreak`（仅以技术手段参考开源思路：KOReader/Legado 的流式布局、增量索引、章节识别规则集——只借鉴思路，不复制其代码）。
>
> **技术栈**：ESP-IDF / C / libunibreak / FatFS / ST7305 / PSRAM 静态缓冲 / FreeRTOS 单后台索引任务。

---

## 0. 现状问题与重构原则（Why）

| 问题 | 根因 | 重构方向 |
|---|---|---|
| 打开书籍卡 1~2 秒，甚至死机(WDT) | 主线程同步索引大书、后台重建目录抢 SD 读卡 | **打开零同步索引**，一律后台小步索引，主线程只回成功 |
| 旋转后书架与阅读方向相反 | 书架 `st7305_set_rotation` 与阅读器自管旋转各一套、映射不一致 | **单一旋转源**：旋转值只由 NVS 一份，书页/阅读/触摸共用同一套坐标映射 |
| 目录只有「简介」/识别错乱、含前导空格 | `utf8_num_word` 用了 Unicode 码点(4E00)却读 UTF-8 字节(E4B880)永不匹配；标题按原文带缩进存储 | 统一按 UTF-8 字节匹配数字/后缀；标题存去缩进后的干净字符串 |
| 目录不完整（只有侧边缓存里那几条） | 旧 `.idx` 只存了很少章，且完整缓存时不再重建 | 索引版本号升级强制重建一次；目录后台逐步填充并即时显示 |
| 字体大小/字体弹出的滚动拖不了、不跟手 | 列表是整行跳变，无像素偏移，无可拖滚动条 | 菜单列表改为**像素级跟手**，右侧画 Windows 式轨道+滑块并可拖 |
| 分类分散、改一处连带 bug | 单文件 `book_reader.c` 超过 2600 行 | 拆分为职责单一的多文件模块 |

**不复制代码**：以下所有接口/结构均为本项目重新设计，仅参考技术概念（流式布局、增量索引、章节正则思路）。

## 1. 目标结构（文件划分）

重构 `components/book_reader/`：

```
components/book_reader/
  book_reader.h          # 对外 API（与 os 层接口，保持稳定）
  br_core.c/.h           # 阅读会话：打开/关闭/翻页/断点/书签 状态机（轻，无渲染）
  br_index.c/.h          # 索引：页偏移表(PSRAM 静态)+后台任务+断点续扫+侧边 .idx 读写
  br_toc.c/.h            # 目录：章节识别(规则集)+预扫描+兜底分节+目录菜单模型
  br_font.c/.h           # 字体：内嵌字库+TF卡字库+字号/行距/边距等版面参数
  br_rotate.c/.h         # 旋转：单一旋转值、坐标映射、pfb 竖屏缓冲
  br_render.c/.h         # 排版/绘制：横竖屏渲染、markup、进度条
  br_menu.c/.h           # 阅读菜单：目录/书签/字体选择 的超长窗口(像素跟手+滚动条)
  br_setting.c/.h        # 设置加载/保存(NVS)、与书库「阅读优化」共用同一份旋转定义
  book_flow.c            # 保留(排版内核 libunibreak)，作为只读依赖
  font_book.c/.h         # 保留(字体字形加载/绘制)，作为只读依赖
  CMakeLists.txt
```

依赖：`st7305 driver fatfs freertos esp_timer audio_player fonts nvs_flash input book_flow`

## 2. 旋转（最高优先级 A）

原则：**一份旋转值，一套坐标映射**，书架、阅读、触摸输入都用它。

- 旋转值存 NVS `rt`（0上/1下/2左旋90/3右旋90，顺时针）。
- 阅读器打开时 `input_set_screen_rotation(s_rot)`；退出设 0。
- 统一坐标换算函数（在 `br_rotate.c`，供触摸与绘制共用）：
  - 逻辑宽/高：横屏 `400×300`；旋转 2/3（竖屏）逻辑 `300×400`。
  - 触摸原始坐标 → 逻辑坐标：与 input.c `rotate_screen_coord` 同规则。
- `book_reader_open` 从书库传入 `s_bs_rot`（同一份），实现书架→阅读方向一致。

验证：旋转 2/3 时书架竖屏与阅读竖屏方向一致，左右翻页方向正确。

## 3. 目录 / 章节识别（最高优先级 A）

- 识别规则子集（规则判定作为独立模块，供预扫描与分页共用）：
  - A：`第[数字][章回节卷部话集篇]`
  - B：特殊章名（序章/楔子/正文/终章/后记/尾声/番外）
  - C：数字(半角/中文)+分隔符+标题
  - D：英文 Chapter/Section/Part/Episode...
  - E：卷前缀式（卷一）
  - 反证排除：`部+分/赛/游/帮`、裸「第X」（无后缀）不判为章。
- **数字匹配按 UTF-8 三字节码**（一=E4B880），杜绝 Unicode 码点误用（旧目录为空的真因）。
- 标题存储：去行首缩进、截断到 31 字节。
- 预扫描：后台任务逐行扫描全书填目录，**每 2 块 `vTaskDelay(1)`** 让出 SD/CPU，**即时渐进填充**（目录菜单边扫边显示），完成后回写 `.idx`。
- 兜底：扫描无结果时按字数分节（“第N节”），保证总有目录可跳。
- `.idx` 版本号由 `06→09`，旧缓存自动失效重建。

验证：蛊真人.txt 打开后目录显示「第一卷 / 第一节：…」，无「简介/裸第一」，数量≈6卷+2340节。

## 4. 字体与版面（最高优先级 A）

- 内嵌仿宋/黑体 ×16/24/32（`font_book`，mmap 只读，保留）。
- TF 卡字体：`.fnt`（保留）；仅为**参考** `.cpfont`/OTF 的“字形集+间距”概念扩展，不改字体引擎，只加字体选择与字号维度。
- 版面参数（字号/行距/边距/字距/缩进/夜间/页码）集中到 `br_setting`，改任一 → 后台重排一页即可读，页面按字节偏移恢复。
- 字体选择菜单与字号选择：复用通用的像素跟手列表（见 §6），松手选中生效并重排。

验证：切换内嵌/卡字体、16/24/32 字号后，当前页立即按新版面重排，断点不错位。

---

## 5. 索引与“瞬间打开”（优先级 B）

- `book_reader_open` 主线程**零同步索引**：打开文件、嗅探编码、分配静态 PSRAM 缓冲、载入侧边 `.idx`（页表）、载入进度，立即返回。
- 后台单任务 `br_index`：断点续扫（256KB/步 + 5ms + 喂 WDT），首段 48KB 快速生成第 1 页。
- 页偏移表用**静态 PSRAM 预留**（不逐页 realloc），上限封顶，杜绝堆碎片/sidecar 一次性大分配。
- 渲染遇未索引页：`book_wait_indexed_page` 仅**有界 ≤800ms**，超时不阻塞，页表就绪即出字。
- 侧边 `.idx`/`.pos` 用小步分片落盘，绝不阻塞主线程。

验证：点击书籍**瞬间**进入可读，无 1 秒等待；连续快速翻页不卡不死。

## 6. 阅读菜单超长窗口：像素跟手 + 可拖滚动条（优先级 B）

通用列表组件 `br_menu`（目录/书签/字体选择共用）：
- 全屏超长窗口（`W-8 × H-8`），目录**左对齐**，其它居中。
- **像素级跟手**：维护 `s_menu_pix(0..ROW_H-1)`，拖动时内容 1:1 随手指平滑移动，选中行高亮随行随动。
- **Windows 式右侧滚动条**：轨道(浅) + 滑块(实心)，反映可视比例与位置；**可直接手拖滑块**跳转。
- 拖动后松手**不触发跳转跳章**（抑制点击）。
- 结构：`book_menu_geom`(绘制/触摸共用几何)、`br_menu_poll`(poll 读 `input_get_touch_pos`)、`br_menu_draw`、`br_menu_hit`。

验证：目录可手指平滑拖动、可拖滚动条到末尾章节、松手不误跳。
