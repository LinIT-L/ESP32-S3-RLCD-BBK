## 4. Wi-Fi 扫描列表页细则
- 进入即自动扫描（`wifi_manager`）；扫描中显示 `SCANNING..`。
- 无网络：`NO NETWORK FOUND`；出错：`SCAN FAILED`。
- 每行固定约 208px 高度内容：

- 底部：选中项摘要 `[n/N] 加密方式 RSSI CH 确认:CONNECT`。
- 排序：RSSI 降序。

## 6. 全屏输密码页细则

# 网络工具「NETTOOL」产品方案（旧版·作废存档）

> 面向 ESP32-S3 · 400×300 1-bit LCD · 电子词典复古风
> 双交互：触屏（点选/拖动）+ 物理按键（方向键/确认/返回）
> 迭代阶段：本期联网四入口（体检/扫描/路由/服务），二期侦听

---

## 0. 目标与定位

把设备变成一台 **局域网体检仪**：在同一台 400×300 屏上，分 4 个工具页，
检测 **自己网络是否健康 + 网内每台设备是谁 / 开了什么 / 有没有裸奔服务 + 网络服务（文件共享/打印机）是否被开启**。
归属类（IP 运营商、MAC 厂商）一律走免费云接口免本地计算；探测类（在线/端口/时延）现场直测。

**范围红线（用户已拍板）：**
- 不做漏洞库 CVE / 不做网络吞吐 / 不做 USB 网卡（WiFi-only）
- 「网络服务」= 仅监测识别**是否开启（对应 IP）**，不浏览共享文件、不实际打印
- 归属类功能全走免费接口，接不通就换源，不反复死磕
- 二期的「空中侦听」须断开 WiFi，本次不做

## 1. 信息架构

入口：**主菜单 → 迷你应用 → NETTOOL（"网络工具"）**

```
NETTOOL
 ├── ① 网络体检   本机质量：信号/延迟/丢包/DNS/公网 + IP归属(运营商省市)
 ├── ② 局域网扫描  ARP找设备 + MAC/厂商 + 端口 + 弱配置 + IP冲突
 ├── ③ 路由追踪   预设10公共节点/自定义 + 逐跳IP/时延/丢包/卡顿点 + 每跳归属
 ├── ④ 网络服务   识别共享(SMB/NFS/AFP) + 打印机(IPP/RAW/515 + mDNS型号) → 报IP
 └── ⑤ 空中侦听   (二期, 需断WiFi) 附近WiFi/被动设备/异常告警/DNS审计
```

各入口相互独立，均可单独进入；扫描/追踪后台任务跑，UI 实时读状态不阻塞。

## 3. UI 设计体系

### 3.1 视觉规范（遵守既定 icon 规范）
- **1-bit 双色**：仅黑/白，无灰度、无描边柔化
- **线条**：优先 1px，结构/强调 2px，直角/阶梯斜边，禁抗锯齿
- **风格**：Game Boy + 电子词典复古质感
- **高亮**：焦点项用**细方框描边**（不反白填充，与既有规则一致）
- **排列**：图标 40~48px，间距均衡，无边框装饰

### 3.2 布局骨架（每页通用）
```
┌────────────────────────────────┐  y=0
│ 标题(中文24px)   ···· 提示      │  状态行高 28
├────────────────────────────────┤
│                                  │

│                                  │
```

### 3.3 交互模型（双输入统一）
- **焦点唯一**：全局 `cur` 索引表示当前项，触屏点中即移焦并进入；按键移动焦点、确认进入。
- **主页菜单**：2×2 网格（四个大图标 + 下方小字），方向键上下左右移动，确认进入，返回退主页。

### 3.4 状态行
顶部显示：当前页面名 + 右上角连接状态点（●=已连/○=未连），让用户一眼知道能不能联网测。

## 4. 各入口详细设计

### 4.1 主页（NETTOOL 首页）
- 标题行：`网络工具`
- 中部 2×2 网格 4 枚图标（体检/扫描/路由/服务），每图标 44×44，下方 24px 中文小字
- 焦点图标 2px 细框描边
- 底部提示行：`上下左右移动  确认进入`

### 4.2 ① 网络体检
布局：标题行 `网络体检` → 下面是状态卡片列表（每行一个指标）。
- `信号    -65dBm`   ← WiFi RSSI
- `网关    5ms`      ← 到网关延迟（ping 网关均值）
- `丢包    0%`
- `DNS     12ms`     ← 解析速度
- `公网    通/不通`
- 末行：`归属  中国电信 · 广东-广州` ← 云接口查本机出口IP
- 交互：进入即触发一轮综合体检；完成后 UP/DOWN 滚动查看；CONFIRM 重测。
- 数据流：本地取 RSSI/网关 ping；云接口取归属。

### 4.3 ② 局域网扫描（升级现有 NETSCAN）
- 顶部：本机 IP + 网关（复刻现有显示）
- 中部：主机列表（每行 `IP ... 开放数`，焦点细框）
- 底部：选中主机的详情条（`SEL >>> FTP SSH HTTP` 已开放端口）
- **新增 vs 现有 NETSCAN：**
  - 找设备 ICMP 保持（已有），弱配置标记：开放 TELNET/FTP/SNMP 的主机行右侧加 `!` 警示
  - 可增加 MAC + 厂商（云接口）：列表选中时详情区显示 `MAC xx:xx:..  厂商=xxx`
  - IP 冲突检测：扫描时若发现网关 IP 被冻结上报 → 提示「疑似 IP 冲突」
- 交互：CONFIRM 开始/重扫；UP/DOWN 选主机；选中后 DOWN 查看该机全部开放端口+MAC+厂商。

### 4.4 ③ 路由追踪
- 顶部：目标选择条（方向键在预设节点间切换）
- **预设 10 节点**（内置）：
  国内 DNS：`223.5.5.5 阿里` / `119.29.29.29 腾讯` / `180.76.76.76 百度` / `114.114.114.114 114DNS`
  国内门户：`www.baidu.com` / `www.taobao.com` / `www.jd.com` / `www.qq.com`
  国际：`8.8.8.8 Google` / `1.1.1.1 Cloudflare`
  （可加自定义输入 IP/域名，二期）
- 中部：逐跳列表（`跳1  IP  12ms` / 每跳含丢包），延迟偏高跳标 `!`
- 底部或详情：该跳反向 DNS / 归属（云接口尽力）
- 数据流：本地发送 TTL 递增探测包；云接口查每跳 IP 归属。

### 4.5 ④ 网络服务
- 目标：识别局域网里是否开启以下服务并报 IP（**不浏览、不打印**）
- 网络共享：SMB(445) / NFS(2049) / AFP(548)
- 网络打印机：IPP(631) / RAW(9100) / 515 + mDNS 打印服务发现（`_ipp._tcp` 等）→ 显示打印机型号+IP
- 布局：类似扫描，分成「共享服务」与「打印机」两组，列出 `服务名   IP`；焦点选中，确认看详情。
- 数据流：对存活主机探测上述端口 + mDNS 发现打印服务。

## 5. 云端接口模块（归属类）

**统一原则：** 所有归属/身份查询走同一个 HTTP 查询模块，免费接口，接不通换源。

| 用途 | 入参 | 出参 |
|---|---|---|
| IP 归属 | 本机出口 IP 或 目标 IP | 运营商 + 省市 |
| MAC 厂商 | MAC:`AA:BB:CC` | 厂商名 |
| 节点归属 | 每跳 IP | 运营商/机房 |

- 基于 `esp_http_client`（menu 已依赖），串行查询，带超时（如 3s），失败即返回"未知"并容错继续。
- 复用 menu 现有 WIFI_SUPPORT 与 `wifi_manager`（联网状态）。
- 查询结果缓存到静态变量，避免重复请求。

## 8. 边界与诚实约束
