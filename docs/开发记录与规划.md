# 历史记录（已实现/已解决）

## 1. 蓝牙搜索流程修复

**问题**：一进搜索就"未发现设备"——`esp_hid_scan()` 开头检查全局旧结果非空即返回 `ESP_FAIL`，扫描根本没真正开始；返回不重扫。

**目标交互**：进入立即显示"正在扫描…"持续一个周期(约3~5s)；结束有设备则列表连接、无设备显示"未发现"且确认/返回=重新扫描；扫描中返回=停本次并自动重扫。

**改动**：`esp_hid_gap.c esp_hid_scan()` 清理旧结果不再返回 ESP_FAIL；`bt_core.c scan_task` 每次真起扫；扫描用阶段状态机 `SCANNING→DONE`。

**边界**：连续扫描去重；扫描放后台不阻塞 UI；ACE 仅 BLE。

## 2. 科学计算器（page_calculator）

**功能**：四则/幂/取余/阶乘/括号/隐式乘法、三角/双曲/对数/开方及常量 `π/e`/`Ans`、角度弧度切换、虚拟键盘+手柄导航。

**方案**：表达式引擎自研（词法→shunting-yard→后缀，double）；UI 独立页面注册进 os_pages；图标 1bpp 入 icons 库。

**规模**：引擎 + 页面 ≈ 新增 15~25KB Flash，RAM 峰值 <1KB 栈 + PSRAM 缓冲。

## 3. 电子书阅读器（book_reader，V2 重构）

**目标**：解决「打开卡顿/死机、旋转方向不一致、目录识别错乱、字体切换与滚动不跟手」。

**架构**：`book_reader.h`(稳定 API) + br_core(会话状态机)/br_index(页偏移表 PSRAM + 后台任务 + .idx)/br_toc(目录识别)/br_font/br_rotate(单一旋转源)/br_render/br_menu/br_setting。

**关键决策**：
- 旋转值存 NVS `rt`(0/1/2/3)，书架/阅读/触摸共用一套坐标映射。
- 目录数字匹配按 **UTF-8 三字节码**（杜绝码点误用）；后台逐行扫描 + 每 2 块 `vTaskDelay(1)` 渐进填充；`.idx` 版本 06→09 强制重建。
- 主线程零同步索引（瞬间打开）；后台断点续扫；未索引页渲染等待有界 ≤800ms。
- 菜单像素级跟手 + Windows 式右侧滚动条（可拖）+ 拖动松手抑制跳转。

## 4. TF卡挂载/卸载串口切换崩溃（✅ 已彻底解决 2026-08-29）

**结论**：「按需切换 + 纯MSC + 挂载期暂停串口控制台 + 看门狗时限调大」。

- 元凶：`CONFIG_ESP_CONSOLE_SECONDARY_USB_SERIAL_JTAG=1` 卸载驱动后仍写日志 → 崩溃。修法：正常=USB Serial 控制台（不装 TinyUSB）；挂载=切纯MSC（`esp_tinyusb v2.2.1`）；挂载期 `log_console_suspend(true)`，日志写 `/sdcard/log/bbk.log`。
- 卸载重启：`sd_scan` 6 秒看门狗误伤 → 时限 6000→15000~20000ms。

**关键文件**：`usb_hid/usb_hid.c`、`usbh_msc/usbh_msc_sdspi.c`、`main/main.c log_console_suspend`、`sd_scan/sd_scan.c`、`page_storage.c`。

**恢复**：若再陷入无限重启且 USB 串口消失，先进下载模式(BOOT+RST)让 `/dev/cu.usbmodem*` 重现，再烧稳定固件。

# 未来规划（未排期）

## 1. 平台化地基
底层能力做成可拼接能力服务，应用经统一接口（Host API）组合使用（components/platform：能力注册表 + Host API 总线）。

## 2. WASM 应用商店
WAMR 跑 WASM 应用，经 Host API 访问系统能力；WiFi 下载安装，`os_app_register("wasm:<id>")` 动态进主菜单。

## 3. ANCS 手机通知
iPhone 系统级 ANCS 通知（免 MFI、免三方 App）；与手柄蓝牙分时切换；Android 备选 ANP/NotificationListenerService。

## 4. 壁纸可拼屏保
壁纸做成可拼接能力，银河/烟花/海底等屏保各注册一个渲染变体。

## 5. 恢复系统（Recovery）
电源键长按进恢复系统，TF/网络恢复固件 + 核心数据备份（详见《系统设计.md》）。
