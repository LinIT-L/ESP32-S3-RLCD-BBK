# 恢复系统（Recovery）设计方案

> 电源键 = 软关机键。开机**按住软关机键 ≥5s 进恢复系统**，未按则立即正常启动（零等待）；主系统写坏时 bootloader 自动回退进恢复系统。
> 开发阶段，无老数据，appdata 可直接重刷。

## 1. 分区表（partitions.csv，16MB）

```
nvs,        data, nvs,     0x9000,    0x8000,
phy_init,   data, phy,     0x11000,   0x1000,
otadata,    data, ota,     0x12000,   0x2000,
factory,    app,  factory, 0x20000,   0x400000,   # 4MB 主系统
recovery,   app,  ota_0,   0x420000,  0x180000,   # 1.5MB 恢复系统
appdata,    data, 0x40,    0x5A0000,  0xA60000,   # 10.375MB 数据区
```

- otadata：bootloader 用它选 factory/recovery（仅借用引导机制，非空中升级）。
- recovery 用 **ota\_0** 子类型：factory 校验失败时 bootloader 自动回退进恢复系统，无需改 bootloader。
- **appdata 内部布局**（绝对地址，recovery 缩至 1.5MB 后模拟器空间最大化）：

| 段 | 绝对地址 | 大小 | 内容 |
|---|---|---|---|
| 8.BIN | 0x5A0000 | 2MB | 步步高词典字库 |
| E.BIN | 0x7A0000 | 2MB | 步步高屏幕点阵 |
| 字库区 | 0x9A0000 | 4.625MB | font_zh/light/16 + book* + lav_font（槽位固定） |
| 模拟器+配置+WASM | 0xE40000 | **1.75MB** | 各种模拟器 ROM + 普通配置 + WASM 应用 |

## 2. 启动流程

```
bootloader
 ├─ otadata=recovery → 进恢复系统
 └─ 默认 → 校验 factory
       ├─ 无效 → 回退 recovery
       └─ 有效 → 主系统 boot_check 检测软关机键
             ├─ 未按 → 立即正常启动
             └─ 按住 ≥5s → 设 otadata=recovery → 重启进恢复
```

- 恢复菜单"重启设备"：清 otadata → 重启进主系统。
- 软关机为 deep sleep 时，唤醒后 boot\_check 逻辑一致。

## 3. 恢复菜单（7 项）

```
[1] 从TF卡恢复主固件     /sdcard/firmware.bin → 流式写 factory
[2] 连指定服务器恢复固件  连服务器下载 → 流式写 factory
[3] 查看核心数据         设备ID/注册/余额/时长
[4] 导出核心数据         → /sdcard/backup/core.bin
[5] 导入核心数据         ← /sdcard/backup/core.bin
[6] 重置主系统           擦 factory（保留 appdata+recovery）
[7] 重启设备             清 otadata → 进主系统
```

## 4. 网络恢复（菜单\[2]）

- **WiFi：扫描列表 → 用户手动选择 → 输入密码 → 连接**。不用固定凭据、不读 NVS、不依赖主系统配置。
- 服务器 URL 编译期宏（`RECOVERY_SERVER_URL`）。
- HTTP(S) 下载 firmware.bin → 分块擦写 factory（`esp_partition_erase_range` + `esp_partition_write`，不缓存整镜像）。

## 5. 数据存储架构（三级定稿）

| 层级 | 位置 | 内容 |
|---|---|---|
| 重要 | **recovery 分区尾部** 128KB | 核心数据（设备ID / 注册 / 余额 / 时长 / 设备配置），appdata 损坏仍可读 |
| 普通 | **appdata 分区** | 收藏、手柄映射、WiFi 等普通配置 |
| 大数据 | **TF 卡** | 画板 / 白板等，可备份 |

- 核心数据：core.bin + core.bak 双副本原子写 + CRC 回滚；加密（AES/HMAC + eFuse）按需后加。
- recovery 固件实际 0.955MB，数据区固定于分区尾部 128KB，升级/烧录固件不触碰（固件上限 < 1.375MB）。

## 6. 代码结构

```
LinTOS/
├── partitions.csv            # 两个工程共用
├── components/               # 现有组件
├── main/                     # 主系统工程（现有）
│   ├── boot_check.c          # 新增：按住软关机键 ≥5s → 切 recovery
│   └── core_data.c           # 新增：核心数据访问（放 common/ 共用）
└── recovery/                 # 恢复系统独立工程
    ├── CMakeLists.txt        # 只拉精简组件
    └── main/
        ├── main.c            # 恢复主入口（菜单循环）
        ├── menu.c            # 7 项菜单 + 按键/触摸
        ├── wifi.c            # 扫描WiFi → 手动选择 → 密码输入 → 连接
        ├── ota.c             # TF卡 / 服务器下载 → 流式写 factory
        ├── core_data.c       # 与主系统共用
        └── ui.c              # 精简显示（st7305 + 小字库 + 触摸）
```

recovery 只链接：显示 / 触摸 / SD(fatfs) / WiFi(lwip) / HTTP(S) / esp\_partition；不链接蓝牙/USB/手柄/模拟器。

## 7. 构建与烧录

```
# 主系统（bootloader + ptable + app）
idf.py build && idf.py -p /dev/cu.usbmodem* flash

# 恢复系统（独立工程，只烧 app 到 0x420000）
cd recovery && idf.py -B ../build_recovery build
esptool.py -p /dev/cu.usbmodem* write_flash 0x420000 build_recovery/recovery.bin
```

## 8. Recovery 实测体积（已编译 /Users/linit/AI项目/RecoveryOS）

- **recovery.bin = 0.955MB**（0xf46e0），1.5MB 分区余 36%。
- 包含：显示(st7305) + 触摸(touch_panel) + SD(fatfs) + WiFi(lwip) + HTTP(S)/mbedtls + 内置中文字库(78字/5.7KB) + 7 项菜单。
- **RAM ~113KB**（DIRAM 33.75%），512KB 内充足。
- 核心数据区：分区尾部 128KB 双副本（固件上限 < 1.375MB）。
