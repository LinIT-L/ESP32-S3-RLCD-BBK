# 硬件与接口手册

> **这份手册回答"硬件是什么、引脚怎么接、外设怎么用"**。
> 真相源：`components/drivers/board_pins/board_pins.c`（三张表）、`components/services/hw_cfg/hw_cfg.c`（识别）、
> `partitions.csv`（存储）、原理图（`hardware/`）。
>
> ⚠ **本手册的引脚以 `board_pins.c` 为准**。硬件行为（上拉、时序、电流）来自原理图与真机实测，
> 源码只能证明"固件怎么想"，不能证明"板子实际怎样" —— 两者冲突时按 §证据规则处理。

## 怎么读

| 我想知道 | 去 |
|---|---|
| 三块板的引脚表、撞脚、上拉、换板 | 第一部分 |
| 某个外设（屏/触摸/音频/WiFi/BT/GPS/USB/电源/震动/存储）的模块行为 | 第二部分 |
| 功耗与休眠 | 见 [功能专题·电源与休眠](../专题/功能专题/电源与休眠.md) |

## 证据规则

| 级别 | 含义 | 能不能当结论 |
|---|---|---|
| 【源码】 | 引脚表、初始化代码、外设调用 | ✅ 能证明固件行为 |
| 【原理图】 | `hardware/` 里的 PDF / 网表 / BOM | ✅ 能证明电气连接 |
| 【真机】 | 串口日志、实测波形、万用表 | ✅ 最高优先级 |
| 【推断】 | 由代码或文档推导 | ⚠ 必须标注 |
| 【待核实】 | 缺证据 | ❌ 不得写成事实 |

## 第一部分 引脚、板型与撞脚

> 本部分讲：三块板引脚总表、8 脚排针、分区、上拉实测、撞脚、换板。

> 真相源 = `components/drivers/board_pins/board_pins.c`（三张表 + `board_pins_get()`）。
> 识别 = `components/services/hw_cfg/hw_cfg.c`（开机探 I2C 指纹）。
> 引脚数值以 `board_pins.c` 三张表为准（下表已逐项对齐源码）。
> 网表 `.enet` 文件**未随仓库分发**（仓库内无此文件），需要时向维护者索取；微雪商用板无原理图，按官方文档。

| LCD DC/CS/SCK/MOSI/RST | 7/11/9/10/**不接** | 5/40/11/12/**41** | 5/40/11/12/**41** |

| 按键 电源/返回/确认 | 1/0/4 | 非 GPIO/0/18 | 1/0/18 |

| I2S DOUT/DIN | 48/21（模组内部） | 8/10 | 8/**无** |
| codec I2C SDA/SCL | 38/47（模组内部） | 13/14 | —（NS4168 无 I2C） |
| 功放使能 PA | 46（模组内部） | 46 | 46（外部 100k 上拉） |
| 震动 PWM | 8 | 48 | 48 |

| 充电状态 CHRG | 42（**待焊**） | 无 | 无 |
| 识别指纹（I2C） | 38/47 有 `0x18`(ES8311) | 13/14 有 `0x18`(ES8311) | 15/7 有 `0x15`(CST816) || 模块内置 | 充电/降压/功放/解码/麦克风 | 板载充电/降压 | **全部自行外加** |

> **识别顺序是"音频优先"**（`hw_cfg.c` 的 `detect_board()`）：38/47 命中 codec → ①；13/14 命中 → ②；
> 两者都不中再探触摸 15/7 → ③；全不中 → 进识别轮询界面，不启动系统。
> 之所以不用触摸当主判据：触摸排线最容易虚焊，误判会换来黑屏。
>
> **地址容差**：ES8311 试 `0x18` / `0x19`（CE 脚决定）；触摸试 `0x15` / `0x5D` / `0x14` / `0x38`
> （CST816/836、GT911、FT6236）。探触摸前必须先给 RST 一个低→高脉冲并等就绪，
> 否则芯片停在复位态，必然报"无触摸"。
>
> 识别结果落盘 NVS（`board_id` + `det_mask`），之后每次开机**不再重复探测**；
> 换板/改线后要在「设置 → 网络与系统 → 硬件管理 → 重新自检」里重跑。

### 3. 芯片 / 存储 / 分区

- ESP32-S3 + 8MB PSRAM（octal 80MHz）+ 16MB flash。
- 分区见 `partitions.csv`：nvs 256K@0x10000 · factory 5M@0x60000 · appdata 6.625M@0x560000（字库@0x960000）· apps 4M@0xC00000。
- 编译：**ESP-IDF 6.0.3**（`~/esp/esp-idf-v60`），工具链 `esp-15.2.0_20251204`，
  Python 环境 `~/.espressif/python_env/idf6.0_py3.11_env`（均由 `build.sh` 设定默认值，可用同名环境变量覆盖）。

### 4. 外设实测要点

**屏** ST7305 400×300 1bpp 反射，无背光。① 的 RST **不接 GPIO**、只有 10k 上拉（R2）；
②③ 的 RST 都是 **GPIO41**，由固件驱动并拉高（③ 另有 R7 10k 上拉）。
⛔ `(1ULL<<rst)` 必须带 `>= 0` 保护，否则 abort ⇒ 重启循环。

**触摸** CST816/836U，I2C_NUM_1 @100kHz，addr `0x15`。单指；双指仅左右半屏各一点。② 无触摸。

**SD/TF** SDMMC 1-bit。上拉：CMD/D0 各 10k→3V3，卡座 CD/DAT3 10k→3V3。
软件：400kHz 探响应 → 25M/20M/5M/400k 梯度挂载。
⛔ 深睡会 hold SD 三脚 ⇒ 开机必须 `gpio_hold_dis`，否则认不到卡（只能断电）。

**音频** ① ES8311（喇叭）+ ES7210（麦克风）在模组内，I2S 与 codec I2C 都不引出；③ NS4168 纯功放（无 MCLK、无录音）。
功放使能 GPIO46 低有效。⛔ 46 是 strapping，禁内部上拉；③ 有 R15 100k 上拉 ⇒ 上电默认导通，固件要尽早拉低。

**震动** TM6604 + 1508 线性马达，EN 靠电阻常开（① R4 10k→VBAT，③ R16 10k→VBAT）。
⛔ 禁 `gpio_reset_pin()`、禁浮空。

**电池/充电** ③ 分压 R14 200k / R13 100k → GPIO4，比例 ÷3.0（固件常量 3.10）；① 板上无分压，ADC 走模组内 GPIO3。
满电压取 30 天峰值，空 3300mV。充电器：① 模组内 LGS4056HDA · ③ TP4057（只接 LED）。
① 的 `LGS4056_CHRG` → 排针 5（GPIO42，开漏低有效，**尚未焊**）；未焊时用 `usb_hid_host_mounted()` 兜底。

**GPS** MAX-M10S-00B-01，UART1 重映射（不占 UART0）。
① 的 TX/RX 是 ESP32 自己的脚：模组 34 脚 = GPIO41 = GPS RXD，22 脚 = GPIO14 = GPS TXD；UART0（43/44）走排针，不冲突。
引脚 6 档自动波特率 38400 → 9600 → 115200 → 57600 → 230400 → 921600，谁先出 NMEA/UBX 用谁。
电源常通，省电靠 `UBX-RXM-PMREQ`（待机 ≈46µA）；⛔ backup 不保留配置 ⇒ 睡醒靠重认，不做 UBX-CFG-PRT 重配。
GSV 默认 5 秒一次 ⇒ ≥38400 时用 `UBX-CFG-VALSET` 提到 1Hz（9600 不提）。

| 小智 | R4 10k | VBAT ↔ TM6604 EN |

| 小智 | R8 10k · R1/R3 5.1k | 3V3 ↔ 卡座 CD/DAT3 · USB-C CC1/CC2→GND |
| 标准 | R7 / R4 10k | 3V3 ↔ LCD_RESET / EN |
| 标准 | R15 100k · R16 10k | 3V3 ↔ GPIO46（功放）· VBAT ↔ TM6604 EN |
| 标准 | R6 / R5 10k | 3V3 ↔ GPIO21(SD CMD) / GPIO39(SD D0) |
| 标准 | R14 200k + R13 100k | VBAT ↔ GPIO4 ↔ GND（÷3.0） |

### 6. 不能撞的脚

- **8 / 48 两板对调**：① 震动 8 + I2S DOUT 48；②③ 震动 48 + I2S DOUT 8。
- **GPIO40 双义**：②③ 是 LCD CS，① 是 I2S MCLK。
- **① SD 占 15/16/17，③ 占 38/21/39** —— 最易混：③ 的 15/17 只到 LCD FPC（触摸），① 触摸走 5/13/12/6。
- **① CHRG 未焊**：41/42 是 JTAG 脚 ⇒ 外部 JTAG 不可用，烧录走 USB-Serial-JTAG（19/20）。
- **② 的 PWR 不是 GPIO**：接电源锁存 IC（U3/ECJ23001），长按=硬件断电、单击=开机，固件读不到；能读的只有 BOOT(0) 与 KEY(18)。
  `btn_pwr=18` 只用于**深睡 EXT1 唤醒与门控**；`input` 发现与 KEY 同脚会自动禁用"固件电源键"语义。
- ⛔ 改任何引脚前先全工程搜"这个号还有谁在用" —— 撞脚现象与元凶通常毫无关系（EXTINT 设成 8 ⇒ 一直震；MCLK 设成 40 ⇒ 微雪全黑）。

### 7. ⚠ I2C 没有外部上拉

两块自研 PCB 的 I2C（触摸 5/13、codec 38/47）**没有外部上拉**，只靠模组内部弱上拉。
判据：I2C 偶发 NACK / 触摸失灵 / codec 探测失败先怀疑这条，补 4.7k 到 3V3。

### 8. 换板怎么做

1. **直接换板、开机即可** —— `hw_cfg_init()` 探 I2C 指纹自动定板型，不用重编、不用进设置选板。
2. 探不到（改线/换芯片）→ 设置 → 网络与系统 → 硬件管理 → **重新自检**；仍失败则沿用 NVS 上次成功的板型（不会变砖）。
3. 三块板共用 `dist/merged_16mb.bin`，只维护这一个固件。

## 第二部分 外设与系统模块

> 本部分讲：显示/触摸/输入/音频/WiFi/蓝牙/USB/GPS/电源/震动/存储的模块行为与硬约束。

> 模块地图：每个外设/服务**是什么、入口在哪、有什么硬约束**。
> 引脚数值不在这里重复 —— 见**第一部分**；API 签名以各自头文件为准。
> 真相源：`components/drivers/`、`components/services/`、`components/system/`。

### 1 一览

| 模块 | 组件目录 | 一句话 | 关键约束 |
|---|---|---|---|
| 显示 | `ui/` + `drivers/st7305` | 400×300 1bpp 反射屏，SPI 送帧 | 异步送屏；禁 cache 期间不能刷 |
| 触摸 | `drivers/touch_panel` | CST816/836 单点电容触摸 | 探测前必须给 RST 时序；I2C 无外部上拉 |
| 输入 | `system/input` | 物理键 / 触摸 / 手柄的统一动作码 | ISR 只置标志 |
| 音频 | `services/audio_player`、`tone_player` | MP3/PCM 播放 + 提示音 | 合成必须在模拟任务内；`audio_out` 固定 CPU1 prio 8 |
| Wi-Fi | `services/wifi_manager`、`net_client` | 连接管理与 HTTP | 按需启停；TLS 需要连续内部 RAM |
| 蓝牙 | `services/bt_ctl` | **仅 BLE** HID 主机（手柄/键鼠） | 无经典蓝牙；一轮回连 14s 预算 |
| USB | `services/usb_hid`、`usbh_msc`、`usb_net`、`usb_bt` | 键鼠 / U 盘 / 网卡 / 蓝牙桥 | 退出必须关，否则串口消失 |

| 震动 | `services/vibrator` | TM6604 线性马达 | 禁 `gpio_reset_pin`、禁浮空 |
| 存储 | `drivers/sd_scan`、`services/svc_nvs` | TF 卡与 NVS | 深睡 hold 引脚需 `gpio_hold_dis` |
| 电池 | `drivers/board_battery` | 电压采样与 30 天波形 | 落盘 1 小时/次 |

### 2 显示（`st7305`）

- 面板 ST7305，400×300，**1bpp，无背光，断电保留画面**。
- SPI 33 MHz 请求（实际 80/3 ≈ 26.7 MHz），整帧 15000 字节约 3 ms。
- 送屏是**异步**的，与绘制重叠；同一帧内容未变会跳过送屏（静止界面零功耗）。
- 面板自降档：有绘制回 HPM（≈32 Hz），连续 500 ms 无绘制掉 LPM（≈1 Hz）。
- 常用入口：`st7305_flush()`、`st7305_clear()`、`st7305_invalidate_frame()`、`st7305_idle_tick()`、
  `st7305_set_flush_blocked()`（屏保期间丢弃 flush）。
- ⛔ 帧缓冲与 flush 缓冲**必须内部 RAM**（DMA 要求）。
- ⛔ 写 flash / NVS commit / 深睡期间 PSRAM 不可访问，相关路径的缓冲不能放 PSRAM。

### 3 触摸（`touch_panel`）

- CST816 / CST836U 类，I2C @100 kHz，地址候选 `0x15 / 0x5D / 0x14 / 0x38`。
- 单指；双指只在左右半屏各报一点（不是真多点）。
- **探测前必须先给 RST 一个低→高脉冲并等待就绪**，否则芯片停在复位态，必然报"无触摸"
  （历史上首次开机的误判就来自这里，而且结论会被落盘）。
- I2C 线**没有外部上拉**，只靠模组内部弱上拉：偶发 NACK / 失灵先补 4.7k。
- 旋转页面必须用 `ctx->map_touch` 做坐标映射，⛔ 只在页内换算。

### 4 输入（`input`）

- 统一动作码：`1=UP 2=DOWN 3=LEFT 4=RIGHT 5=CONFIRM 6=BACK 7=HOME`，与 `os_action_t`
  用 `_Static_assert` 钉死。
- 处理长按、连发、手势（底部上滑返回）、物理键与手柄合并。
- 手势返回开关由 `gesture_back` 统一管控，随 `os_push`/`os_pop` 联动。
- ⛔ ISR 只做置标志/发队列；不 malloc、不打日志、不碰 I2C。

### 5 音频

两条独立通路：

| 通路 | 用途 | 特点 |
|---|---|---|
| `audio_player` | MP3 / PCM 流播放 | 环形缓冲 + I2S，`audio_player_feed_pcm()` 供数 |
| `tone_player` | 提示音 / 按键音 | 单音与旋律，`app.tone_async` 走这里 |

硬规则（[架构与工程约定](系统整体设计手册.md) §9）：

- **引擎音频合成必须在模拟任务内完成**，只把 PCM 塞进环形缓冲；不要为引擎另起"音频任务"。
- 必须独立音频任务时（SDL 回调模型）：钉 **CPU1**、prio **≤ 8**、并带"单次回调超时 → 关该模块"兜底。
- 验证只看日志：`remcon audio` 的 `underruns` 持续增长 + `play` 远低于 `want` ⇒ 生产端供不上。

### 6 Wi-Fi 与网络

- `wifi_manager`：连接/断开/重连、SSID 与凭据（NVS `wifi_cfg`）。
- `net_client`：HTTP 客户端（`esp_http_client` + `crt_bundle`），8 KB 读缓冲，支持边收边算 CRC。
- **按需启停**：开机不拉射频；谁要联网谁 `os_hw_request(WiFi)`，用完 `os_hw_release`。
  历史上收藏夹/密钥/手柄三页重复 request 导致"取消连接后射频常开"。
- ⚠ TLS 需要**一整块连续内部 RAM**（约 16 KB）：内部堆 `largest` 低于 8 KB 就会
  200 µs 内返回 `ESP_ERR_HTTP_CONNECT`（28674）。验收标准见架构文档 §6.1。

### 7 蓝牙（`bt_ctl`）

- **只支持 BLE**（ESP32-S3 没有经典蓝牙），做 BLE HID **主机**：手柄、键鼠。
- 身份判定用**名字**而不是 MAC（这只手柄会漂地址，同名即同一只）。
- 手柄档案表存 NVS（键 `gpm`），最多 6 只，每只一套 {键映射/补充映射/GB 映射}。
- 回连预算一轮 14 s，用尽即关射频等唤醒。
- ⛔ 经典蓝牙手柄（老 PS4 模式、部分 Xbox、早期国产柄）本来就连不上，
  **不要为兼容它们改代码，也不要把它们当"兼容性差"的证据**。
- ⛔ `bt_ctl` 的 `.bss` **不能迁 PSRAM**：`bt_init` 任务静态栈会走禁 cache 路径。

### 8 USB

| 模块 | 角色 | 注意 |
|---|---|---|
| `usb_hid` | 设备侧 HID（仿真键鼠）| 退出没关 ⇒ **串口消失**（被 HID 占用）|
| `usbh_msc` | 主机侧 U 盘 | 与 SD 共用文件浏览 |
| `usb_net` | USB 网卡（RNDIS/ECM）| 需明确开关，常开会耗电 |
| `usb_bt` | USB 蓝牙桥 | 同上 |

- 烧录走 **USB-Serial-JTAG（19/20）**；小智版 41/42 被 GPS/CHRG 占用 ⇒ **外部 JTAG 不可用**。
- 设备在 app 运行态直连会 `No serial data received`。

### 9 GPS（`gps`）

- MAX-M10S，接 UART1（重映射，不占 UART0）。引脚：小智 41/14，微雪与标准 43/44。
- 波特率自动协商：38400 → 9600 → 115200 → 57600 → 230400 → 921600。
- 电源常通；省电靠 `UBX-RXM-PMREQ`（待机约 46 µA）。
- ⛔ backup 不保留配置 ⇒ 睡醒靠重认，不做 `UBX-CFG-PRT` 重配。
- 经纬度走**整数微度**（`LUA_32BITS` 下 Lua 数字是 float，只有 7 位有效）。

### 10 电源（`power_mgr`）

- **深睡与关机的唯一实现**，别处不许自己调 `esp_deep_sleep_start`。
- 开机第一件事是 `power_mgr_wake_gate()`：手动关机唤醒要求 PWR 按住 ≥0.5 s，误触直接回深睡。
- `power_stat_init()` 结算上次睡眠时长（电池信息页用）。
- 屏保与关机时间：NVS `os_wp` 的 `wp_shut`，唯一入口是「设置 → 休眠与电源」。
- ⛔ `esp_pm_lock` 必须配对 release，最小持有，不在 ISR 里操作。

### 11 震动（`vibrator`）

- TM6604 + 1508 线性马达，LEDC PWM 驱动（频率对准 LRA 谐振点）。
- 引脚来自 `board_pins`：小智 **8**，微雪与标准 **48**。
- ⛔ 禁 `gpio_reset_pin()`、禁让 EN 浮空（会有持续微震）。
- UI 反馈统一走 `vibrator_tap_ui()`。
- ⚠ `vibrator.h` 头注释仍写「PWM←GPIO42 / EN←GPIO48」，那是早期版本的值，
  与当前 `board_pins` 不一致 —— **以 `board_pins.c` 为准**，该注释待修正。

### 12 存储与电池

- `sd_scan`：SDMMC 1-bit，400 kHz 探响应 → 25M/20M/5M/400k 梯度挂载；
  挂载是异步任务，进桌面前由 `sd_wait_ready(1500)` 收口。
- `svc_nvs`：NVS 封装，命名空间归属见[设置与存储归属](系统整体设计手册.md)。
- `board_battery`：电压采样（分压比 ÷3.0，固件常量 3.10），7 天分钟级波形 + 31 天日档，
  落盘节拍 1 小时/次。
