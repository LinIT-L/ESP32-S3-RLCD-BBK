# 未来扩展计划

> LinTOS 已排期 / 在评估的未来功能，统一收口于此。

## 1. 平台化地基
把底层能力做成可拼接的能力服务，应用经统一接口（Host API）组合使用。
新增 components/platform：能力注册表 + Host API 总线。
能力：显示 / 输入 / 音频 / HID / 存储 / 网络 / 蓝牙 / 震动 / 电池 / 时间 / 弹窗 / 音量。

## 2. WASM 应用商店
WAMR 跑 WASM 应用，经 Host API 访问系统能力；WiFi 下载安装，os_app_register("wasm:<id>") 动态进主菜单。

## 3. ANCS 手机通知接收
- iPhone 系统级 ANCS，无需 MFI 认证、无需第三方 App，像 Garmin 手表收通知。
- 作为 plat_bt 子能力，单独新模块 ble_notify（与 bt_ctl 手柄零共享）。
- 注意：ANCS 占蓝牙射频，大概率无法与手柄同时工作，需分时切换。
- Android 备选：ANP / NotificationListenerService。

## 4. 壁纸可拼屏保
壁纸做成可拼接能力，银河/烟花/海底等屏保各注册一个渲染变体。

## 5. 恢复系统（Recovery）
电源键长按进恢复系统，TF/网络恢复固件 + 核心数据备份。
