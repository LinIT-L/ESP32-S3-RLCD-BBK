# 数码暴龙机（Digital Monster / V-Pet）方案

> 目标：在 **ESP32-S3-RLCD-BBK** 固件上实现一台「数码暴龙机」。
> 基础机制与原版（1997 Digital Monster / 数码暴龙机）**一模一样**，
> 在此之上用**模块化、数据驱动、可扩展**的架构承载大量额外养成系列与功能。
> 最后为 400×300 1bit 反射式屏（ST7305）绘制**黑白精细 UI**。

---

## 1. 总览

```
┌─────────────────────────────────────────────────────────────┐
│  主菜单 (menu_system) 新增 "数码暴龙机" 图标                    │
│  └─ VPET 组件 (components/vpet)                            │
│       ├─ 核心引擎 core/   (与硬件无关的纯逻辑, 可单测)           │
│       ├─ 数据表 data/     (进化树/系列/技能/图鉴 = "ROM"数据)    │
│       ├─ 平台适配 platform/ (st7305/input/audio/nvs/rtc)      │
│       ├─ UI      ui/     (黑白精细渲染)                        │
│       └─ 扩展    ext/     (战斗/图鉴/迷你游戏/成就...)          │
└─────────────────────────────────────────────────────────────┘
```

设计三原则：
1. **核心与硬件解耦**：养成逻辑是纯 C 状态机，可在 host 上编译单测（复用 BBK 的 R7 模拟思路）。
2. **数据驱动进化**：每一个「版本/系列」就是一张数据表（对应原版 DM Ver.1~5、Pendulum 等），引擎不写死任何进化分支。
3. **扩展即插模块**：战斗、图鉴、迷你游戏、成就等以独立模块注册，不侵入核心。

## 2. 硬件基础（复用本项目）

| 资源 | BBK 现状 | V-Pet 用途 |
|---|---|---|
| MCU | ESP32-S3 240MHz / 8MB PSRAM / 16MB Flash | 充裕，V-Pet 逻辑极轻 |
| 屏幕 | ST7305 反射式 **1bit** 400×300 | 黑白精细 UI，2× 放大 128×? 核心区 |
| 按键 | KEY(GPIO18)=确定/多功能、BOOT(GPIO0)=右/返回、PWR(GPIO1)=锁屏/关机/返回 | 主交互：A/B/方向 |
| 触摸 | CST816 | 点按/滑动，丰富交互与迷你游戏 |
| 音频 | tone_player(GPIO48 方波) + audio_player(可选 ES8311) | 电子音效（呼叫/训练/进化/战斗） |
| 时间 | RTC/网络/菜单时间 | **离线成长**计时基准 |
| 存储 | NVS + SD | 存档、图鉴、多存档槽 |
| 蓝牙 | bt_manager | 未来「双机对打」数据链接 |

> 关键点：屏幕是 **1bit 黑白**。原版 DM 本就是 32×24 左右的单色像素屏，BBK 的 400×300 1bit 屏做「大图标 + 精细描边」反而更贴合原版气质。

## 3. 基础机制（与原版一模一样）

### 3.1 生命阶段（成长状态机）

```
蛋 Egg
 │ 孵化(约10秒)
 ▼
幼年I Baby I (幼年期I)   —— 无训练，仅喂食，约 1~2 分钟
 ▼ 自动/喂食触发
幼年II Baby II (幼年期II) —— 喂食/清理，约 5~10 分钟
 ▼ (达到成长期时长)
成长期 Child (成长期)     —— 开始可训练/对战，**主要养成期**
 ▼ (满足进化条件)
成熟期 Adult (成熟期)
 ▼
完全体 Perfect (完全体)
 ▼
究极体 Ultimate (究极体)
```

- 每个阶段有固定「最小停留时长」，到达后按**进化判定**走向下一阶段。
- 成长期之后是否进化、进化成哪条线，由「照顾失误数 + 胜利数 + 体重 + 训练」共同决定（对应原版 Ver.1~5 的判定表）。

### 3.2 养成操作（原版按键/菜单动作）

| 操作 | 效果 | 对应原版 |
|---|---|---|
| 喂食 料理(Meat) | +1 饥饿心，体重+1 | 喂食 |
| 喂食 零食(Snack) | +0.5 饥饿心，体重+2，体力度微增 | 零食 |
| 清理大便 | 保持卫生，避免生病 | 清理 |
| 训练(力量) | 体力度↑、疲劳↑、体重↓ | 训练 1 连打 |
| 训练(智力) | 智力度↑、疲劳↑ | 训练 2 |
| 对战(训练赛) | 胜利数±、成长 | 训练对战 |
| 吃药 | 生病时恢复 | 吃药 |
| 训斥(教养) | 教好规矩，减少无意义呼叫 | 训斥 |
| 哄睡/叫醒 | 管理睡眠作息 | 睡眠开关 |
| 呼叫回应 | 满足真实需求 | 应答 |

### 3.3 核心数值

| 数值 | 范围 | 说明 |
|---|---|---|
| 成长阶段 | Baby I..Ultimate | 决定可做操作与外观 |
| 年龄 | 天数 | 从蛋开始计时，驱动时间进化 |
| 体重 | g | 喂食↑、训练↓；影响进化分支 |
| 饥饿心 | 0~4 | 归零→呼叫；长期为 0→扣体心/照顾失误 |
| 体力度 | 0~? | 训练│对战获得；影响进化 |
| 智力度 | 0~? | 训练│对战获得；影响进化 |
| 疲劳度 | 0~? | 训练│对战累积，过高生病 |
| 生病 | 0/1 | 体心透支/太脏→生病，需吃药 |
| 教养值 | 0~? | 呼叫时训斥增长；高教养→稳定进化 |
| 照顾失误 | 0~? | 关键！累积影响进化分支 |
| 胜利数 | 0~N | 对战胜场；影响进化分支 |
| 死亡 | 0/1 | 严重忽视→死亡（可复活/重开） |

### 3.4 照顾失误（Care Mistakes，原版核心）

出现以下任一行为即记 1 次失误（影响进化分支与寿命）：
- 大便存在过久未清理；
- 呼叫无人理会（尤其是夜里/饥饿时）；
- 该睡时不睡 / 该醒不醒（睡眠作息紊乱）；
- 生病没及时吃药；
- 训练过度导致生病。

### 3.5 呼叫与提示

- 需要喂食/清理/睡觉/生病/寻求抚摸时，屏幕动画 + **电子音效**呼叫（复用 tone_player）。
- 无原因呼叫时训斥→教养↑；若误训斥会伤心（体心微降）。

### 3.6 进化判定（数据驱动，非写死）

「进化」由一张**判定表**描述，例如（示意，非定稿数据）：

```
from: 成长期 Agumon
  to  Greymon      : 年龄>=1天 且 照顾失误<=4 且 胜利>=0  且 体重适中
  to  Meramon      : 年龄>=1天 且 照顾失误<=4 且 胜利>=0  且 体重偏高
  to  Birdramon    : 年龄>=1天 且 照顾失误<=4
  to  Garurumon    : 年龄>=1天 且 照顾失误>=5
```

引擎只读表；**添加新系列 = 新增一张表**，不改引擎代码。

### 4.1 对接 BBK 菜单（接入点）

仿照现有引擎注册方式（`engine_manager` + `MENU_PAGE_GB_GAME` 分栏页模式）：

1. 主菜单新增图标「数码暴龙机」→ 进入 `MENU_PAGE_VPET`。
2. 在 `main.c` 主循环里，当 `current_page == MENU_PAGE_VPET` 时，把 `menu_render` 交给 `vpet_render`、`menu_handle_action` 交给 `vpet_handle_action`（与 Arduboy 内置游戏同款模式）。
3. 触摸手势（点按/滑动）映射到 V-Pet 的 A/B/方向。
4. 退出：BOOT 长按 / PWR 0.5s（复用现有返回逻辑）。

### 4.2 时间与离线成长（关键）

- 用 RTC/菜单时间作为「现实时间基准」。
- `vpet_time` 维护虚拟时间轴：**每次进入时用 (now - last_save) 快进**，模拟离线期间的饥饿/睡眠/失误/成长。
- 这是「养成」的精髓：哪怕关机数小时，回来时数码兽的状态也是真实演进过的。
- 存档槽：至少 3 个（NVS内置 + SD 备份），支持多只数码兽转生/轮换。

## 5. 扩展功能路线图（模块化，逐个实现）

每个扩展独立成 `ext/xxx.c`，通过 `vpet_core` 暴露的**事件钩子**（on_frame / on_birth / on_evolve / on_care / on_battle_win ...）挂接，互不侵入。

### 扩展 1 · 多系列数码兽数据（核心扩展）
- 内置 DM Ver.1~5 + Pendulum 进化树数据表，玩家可切换「所选系列」重新开蛋。
- 每个系列不同：进化分支、技能、外观、数值成长曲线。
- 数据全部走 `vpet_series` 表，引擎零改动。

### 扩展 2 · 对战系统
- **训练对战**：本地连打/回合制，胜利→胜利数↑、体心↑。
- **联机对战**：预留接口（蓝牙 bt_manager / 未来 LoRa），握手→同时出招→结算。
- 属性克制（疫苗 / 数据 / 病毒）表，影响伤害。

### 扩展 3 · 图鉴集齐（Digimon Index）
- 收集「已孵化/已进化/已战胜」的数码兽种类，形成图鉴。
- 集齐奖励：解锁隐藏系列 / 特殊训练。

### 扩展 4 · 迷你游戏
- 内置 2~3 个黑白小游戏（如「训练连打」「找食物」「节奏安抚」），提升亲密度/体心/智力。
- 复用 current BBK 的触摸滑动手感。

### 扩展 5 · 昼夜 / 季节 / 天气
- 屏幕随现实时间变「日/夜」背景；特定时间出现特殊事件（夜半惊喜进化、雨天食物打折）。
- 增加「生日/节日」特殊彩蛋。

### 扩展 6 · 成就系统
- 「黑白像素图鉴玩家」「连续 7 天无失误」「三连进化到究极体」等成就。
- 成就进度持久化，解锁称号显示在养成页。

### 扩展 7 · 多存档与转生
- 3+ 存档槽；数码兽寿命结束可「转生」为下一代（继承部分成就/图鉴）。
- 支持「休眠托管」：长时间不玩时进入低功耗待机，回来自动结算离线养成。

### 扩展 8 · 音效与手感
- 用 tone_player 合成原版风格方波电子音（呼叫/喂食/训练/进化/战斗命中）。
- 按键/触摸触发短促反馈音，符合现有系统风格。

### 扩展 9 · 数据分享 / 备份
- 存档导出到 SD（文本/JSON），可备份、可分享图鉴进度。
- 预留「二维码/蓝牙」交换数码兽（未来）。

> 以上为**路线图**，每个扩展先列清单→实现→自测→真机回归，再进入下一个。

## 6. 黑白精细 UI 设计（1bit 400×300）

目标：**原版像素气质 + 本项目极简黑白风格**，避免过度渐变/多彩装饰/冗长说明（符合用户偏好）。

### 6.1 主养成画面（Home）
```
┌──────────────────────────────────────────────┐
│  ▶ 数码暴龙机            [数码兽名]  [年龄]  │  ← 顶栏
│  ┌────────────────────────────────────────┐  │
│  │                                        │  │
│  │          ( 数码兽大图 128×? )           │  │  ← 中央 1bit 精细位图 + 待机动画
│  │           (呼吸/眨眼/睡觉/生病动效)      │  │
│  └────────────────────────────────────────┘  │
│   ❤❤❤♡  饥饿    ★★★☆ 体心    ⚖ 重量   ⚠失误 │  ← 数值条 (实心图标, 用户偏好)
│   阶段: 成长期 Agumon                         │
│   [喂食][训练][对战][清理][设置]               │  ← 底部操作栏 (点按/方向)
└──────────────────────────────────────────────┘
```

### 6.2 设计规范
- **配色**：纯黑底白字 / 纯白底黑字两套皮肤（1bit 唯一自由度），默认白底黑字（反射屏省电清晰）。
- **图标**：实心位图优先（用户偏好），16×16 点阵图标统一尺寸。
- **字体**：复用项目内置点阵字库（黑体 24px 主字 / 16px 辅助），数字/英文用现有 ASCII 点阵。
- **动画**：数码兽 2~4 帧待机/进化闪烁动画，用 `tools/png_to_1bit_inc.py` 把位图转成 `.inc` 数组。
- **布局**：顶栏状态 + 中央主体 + 底部操作栏，间距均衡，无边框装饰（用户偏好）。
- **反馈**：操作成功居中弹窗提示（如「已捕获：按确定继续」风格）—— 与用户收藏成功提示一致。

### 6.3 各界面草图清单
1. 主养成 Home
2. 孵化动画（蛋→幼I）
3. 菜单（喂食/训练/对战/清理/设置/存档）
4. 进化动画（闪烁→变→特效）
5. 对战界面（血条/指令/结果）
6. 图鉴浏览（网格 + 详情）
7. 迷你游戏（3 款）
8. 设置/存档/转生
9. 呼叫/生病/训斥 弹窗

## 7. 实施阶段划分（每步可验证）

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P0** | 搭建 `components/vpet` 骨架 + 对接菜单 + 显示「蛋」 | 从主菜单进入，看到蛋，可退出 |

| **P3** | 数据驱动进化表（DM Ver.1 全线）+ 进化动画 | 成长期→成熟期→完全体→究极体 全链路 |
| **P4** | 训练 / 对战（本地）+ 属性克制 | 训练提升体心，对战计入胜利数 |
| **P5** | 黑白精细 UI 全面打磨 + 动画 + 音效 | Home/菜单/进化/对战手感完善 |
| **P6+** | 扩展 1~9 逐个落地（多系列/图鉴/迷你游戏/成就/昼夜/多存档/转生/备份） | 每扩展独立验收后再进下一个 |

> **P0~P3 是「基础机制与原版一模一样」的落地核心**；P5 单独做黑白 UI；
> P6+ 是「各种额外养成系列与功能」的扩展区。当前阶段：**P0 方案已定，待实现**。

## 附录 B. 风险与注意

- **1bit 屏表达细节的能力有限**：用「大像素 + 动画 + 音效」弥补，不做不可读的小字号文案。
- **时间快进结算**：需防「长时间离线→直接死亡」的挫败感，可加「转生/复活」兜底。
- **与现有菜单耦合**：按 Arduboy 内置游戏模式接入，避免污染 `menu_system.c` 上帝模块。
- **内存**：全部数据表放 Flash（`RODATA`），运行时缓冲放 PSRAM，内部 RAM 只留关键状态。
```
