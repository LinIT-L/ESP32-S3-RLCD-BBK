## 〇、结论先看

| | 结论 |
|---|---|
| **模块是什么** | 工程图纸上放的是 **`ESP32-S3-WROOM-1U-N16R8`**（标准 41 脚）；厂商给它画的自定义封装叫 **`ESP32-S3-AI-2E`**，封装 **47 个焊盘 = 41 可用 + 6 不可用**（与你说的一致） |
| **好消息** | **N16R8 = 16MB Flash + 8MB octal PSRAM**，和现在 LinTOS 的固件配置**完全一致**（`CONFIG_SPIRAM_MODE_OCT` / 16MB QIO）→ **固件内存/Flash 配置零改动** |
| **是什么版本的模块** | **1U = IPEX 天线座版**（不是 PCB 天线）→ **必须外接 2.4G 天线**，否则 WiFi/BT 基本不可用 |
| **必须补的** | 电源开关回路、电池、USB-C+CC、BOOT/RESET、天线、3V3 去耦、VBUS 去耦（7 条，见 §3） |
| **最可能逼你改板/改固件的一处** | 模块**占用了若干标准 GPIO**（网表实证：IO45/IO46 位置是 VBUS/VON，IO47/IO48 位置是 SWVI/SWVO…）→ 你现在用 GPIO45(I2S WS)/GPIO46(功放使能) 的地方可能要挪 |

## 一、这块板的构成（哪些是模块、哪些是你不要的配件）

**模块 U1**（`ESP32-S3-AI-2E` 封装，47 焊盘）

**配件（你都不用了）**：

| 配件 | 器件 | 丝印/证据 |
|---|---|---|
| 4G Cat.1 | `ML307R-DC` + SIM304 卡座 + `BWU.FL-IPEX1` 天线座 + ESD ×3 | dl 图 `ml307` |
| 4G 供电 | `ETA3409S2F` 升压 + 2.2µH(`FTC252012S2R2MBCA`) + 100µF×4 | 同上 |
| 4G 电平转换 | `LMBT3904DW1T1G` ×1 + `MMST3904` ×2 + 分压电阻 | 同上（1.8V↔3.3V） |
| 屏 | **`ST7789-1.54寸` 侧插式液晶**（8 脚 1.0mm 座 `ZX-SH1.0-4PLT`、15P FPC `AFH26-S15FIA-1H`） | 丝印「1.54寸侧插式液晶」 |
| 音频 | 双麦 `TS3425BA`×2、喇叭座、`MK-12C02` 耳机座（带插入检测） | 丝印「双咪头 / 喇叭」 |

## 二、模块自己带了什么（决定了"最少要外接什么"）

从网表逐个焊盘反推：

| 类别 | 焊盘 / 网络 | 你要不要用 |
|---|---|---|
| 电 | `3V3`(2) **模块输出** · `VBAT`(23) 电池 · `SWVI`(24)/`SWVO`(25) 开关进出 · `VBUS`(26) USB 5V | **必须用** |
| 复位/下载 | `RESET`(3) · `BOOT`(27) · `U0TXD/U0RXD`(37/36) | **必须用** |
| USB | `DN`(13) / `DP`(14) | **必须用**（烧录+日志） |
| 屏 | `IO4_SCL` `IO5_SDA` `IO6_DC` `IO7_CS` `IO15_RES` + `IO9_BLK` | 可选（你换自己的屏就重定义） |
| 音频（模块内置 codec） | `VOP/VON`(15/16) 喇叭 · `OUTP/OUTN`(42/43) 耳机 · `MIC1P/N`(30/31) `MIC2P/N`(32/33) · `IO16_INSERT DET`(9) | 不用就**悬空**，⚠ 别当 GPIO |
| 模块内部要求 | `22 ↔ 28` 互连 · `29/34` 接 VBUS 指示灯支路 | **照原样复刻**（漏了可能不开机/灯不亮） |
| 4G 控制 | `IO17_ML307_PWR`(10) `IO1_TXD`(39) `IO42_RXD`(35) | 不用就悬空 |

**关键：`3V3` 是模块输出的** —— 实证：全板 IC 只有 3 颗（U1 模块 / U3 4G / U5 升压），没有独立 3.3V 芯片；`3V3` 网上唯一的"源"就是模块 `2:3V3`，其余全是 LED/上拉/LCD 这些消耗方。
⇒ **模块内含电源管理（充电 + 电源路径 + 3V3）**，你只要给"电池 + USB 5V + 一个开关"。

## 三、只用模块时，这 7 条缺一不可

> **2026-09-30 linit 定案**：**不装电源开关**（`SWVI`↔`SWVO` 直接短接 = 上电即开机）；
> **不装 RESET 键**。这两条的电气要求见下表 ⭐ 行。

| # | 要接什么 | 为什么 | 具体 |
|---|---|---|---|
| 1 ⭐ | **电源开关** `SWVI(24) ↔ SWVO(25)` | 这是模块的电源路径，中间必须有开关 | **决定：直接短接这两脚 → 上电即开机**。代价：没有硬断电手段（"关机"只能靠固件深睡 `wp_power_off`，要彻底断电得拔电池）。**建议留一个 2P 焊盘/排针**，以后想加开关随时能加 |
| 2 | **电池** 到 `VBAT(23)` | 模块内部充电，锂电接这里 | 单节锂电，**先问厂商支持的容量/充电电流** |
| 3 | **USB 5V** 到 `VBUS(26)` + **`VBUS` 上补 ≥1µF + 0.1µF** | 充电 + 供电；原底板**漏了**这颗电容 | 顺手把 `CC` 两颗 5.1k 下拉也带上（Type-C 必须） |
| 4 ⭐ | ~~BOOT(27) + RESET(3) 按键~~ → **只要 EN 的 RC** | **RESET 键可以不要**（烧录/复位都走 USB：`idf.py flash` 靠 USB-Serial-JTAG 自动复位，实测你们 Mac 侧 DTR/RTS 一动就复位）；但 **EN 脚绝对不能悬空** | **✅ 已核实：EN 的 RC 模块内部已带，外部不用补。** 证据：厂商底板网表里 `RESET` 网**只有 `SW5.2`(按键) 和 `U1.3`(EN)**，没有任何上拉/电容 —— 底板能正常启动 ⇒ RC 在模块里面。同理 `BOOT` 网也只有 `SW6.1 + U1.27`，IO0 上拉也不用外部补。<br>**建议留 RESET + BOOT 焊盘/测试点**（不要按键也行，1 个过孔成本 0）：固件跑飞/USB 掉时它是唯一手段 —— 你们刚遇到过"打开 Lua 应用整机重启"，调试期肯定会用到 |
| 5 | **天线**（1U 是 IPEX 座） | 1U 版没有板载天线 | 接 2.4G IPEX 天线；天线周围别贴电池/金属 |
| 6 | **3V3 输出去耦** | 你的外设都从模块 `3V3`(2) 取电 | 就近放 10µF + 0.1µF；**总电流要先问厂商**（LCD 背光+SD+震动是大户） |
| 7 | **`DN(13)/DP(14)` 到 Type-C** | 烧录 + 串口日志都走它 | 内部 USB-Serial-JTAG，无需外部 CH340 |

> ⚠ **顺带提醒（现状就有的坑）**：`IO0 = BOOT = 你现在的"右键"`。上电/复位瞬间**如果右键被按住**，
> 芯片会进下载模式而不是启动固件。现在能跑是因为正常操作不会按着开机，换板后**别把这个按键改到更"顺手"的位置**。

## 四、⚠ 必须先拿到厂商**引脚定义表**（否则不敢画板）

**网表实证：模块把若干"标准 WROOM-1U 位置"改成了自己的功能脚**（这就是"6 个脚不能用"的来源）：

| 焊盘 | 标准 WROOM-1U 是 | 本模块是 | 结论 |
|---|---|---|---|
| 15 | IO3 | **VOP**（音频输出+） | IO3 不可用 |
| 16 | IO46 | **VON**（音频输出−） | **IO46 不可用** ⚠ |
| 22 | IO14 | 与 28 互连 | IO14 不可用 |
| 23 | IO21 | **VBAT** | IO21 不可用 |
| 24 | IO47 | **SWVI** | IO47 不可用 |
| 25 | IO48 | **SWVO** | IO48 不可用 |
| 26 | IO45 | **VBUS** | **IO45 不可用** ⚠ |
| 28 | IO35 | 与 22 互连 | IO35 不可用 |
| 29 | IO36 | VBUS 指示支路 | IO36 不可用 |
| 30–33 | IO37–IO40 | **MIC1P/MIC1N/MIC2P/MIC2N** | IO37–IO40 不可用 |
| 34 | IO41 | VBUS 指示支路 | IO41 不可用 |
| 42–47 | （无，WROOM 只有 41 脚） | `OUTP` `OUTN` + 3 空 + GND | 额外 6 脚 |

**⚠ 最要命的两条**（直接影响你现在这块板）：
- 你现在 **`GPIO45` = I2S WS**、**`GPIO46` = 功放使能(PA_EN)** —— 若模块确实占用了 45/46，**I2S 得换脚**（含 `tone_player`/`audio_player` 的配置）；
- 你现在 **`GPIO4` = 电池 ADC** —— 若模块内部自己做电池管理（E-Gauge/ADC），那电池采样应该改成**读模块**而不是读分压（否则白接一路 ADC，且分压可能与模块内部冲突）。

**要厂商给的清单**：
1. **47 焊盘逐脚定义**（哪 41 个可用、哪 6 个不可用、有没有内部占用）
2. **PSRAM/Flash 具体型号**（必须确认 **N16R8 = 8MB octal**，否则固件要改 `SPIRAM_MODE`）
3. **3V3 输出电流能力 / 充电电流 / 支持的单节电池规格**
4. **`22↔28`、`29/34` 这两处内部要求**（是否必须短接/接 LED）
5. **内置 audio codec 型号 + 控制接口**（不用音频也要知道它有没有占 I2S/I2C 脚）
6. **EN/IO0 内部有没有上下拉与 RC**（决定你外部还要不要补）

## 五、我的建议

1. **如果你要的是"ESP32-S3 核心 + 现成电源管理"**：先拿到 §4 那份引脚表再画板；同时保留你现在的板子作为对照。
   ⚠ 特别确认 **GPIO45/46 与 GPIO4** 这三条，它们是"要不要改固件"的分水岭。
2. **如果你只是想省电源设计**：更稳的做法是**保留现有底板**，只把电源换成已分析过的 **TG28/AXP2101 模块**
   （`docs/电源模块TG28-AXP2101-分析.md`）—— 引脚不动、固件只改电源与电量那几处，风险最小。
3. **别用它的配件**是对的：4G(ML307R) 在底板上还把 **`ML307R_RESET` 悬空**（网表 [E] 级问题），
   加上 `VBUS`/`VDD_EXT` 都缺去耦 —— 这块底板本身就需要先修才能打样。
