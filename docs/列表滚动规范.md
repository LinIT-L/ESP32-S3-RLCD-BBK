# 列表滚动规范（唯一实现：ui_scroll）

> 2026-10-24 linit 定案：**全项目所有列表/文本滚动只允许用 `ui_scroll`**。
> 任何页面不得再自己算 `off`、自己判 `dy`、自己写吸附。
> 组件位置：`components/ui/ui_common/ui_scroll.c/h`

## 三种模式 × 四个开关（页面只调 config，不调参）

```c
ui_scroll_config(&sc, UI_SCROLL_LIST, 0);                      /* 默认：行吸附 */
ui_scroll_config(&sc, UI_SCROLL_PIXEL, 0);                     /* 像素自由 */
ui_scroll_config(&sc, UI_SCROLL_PAGE, 0);                      /* 整页翻 */
ui_scroll_config(&sc, UI_SCROLL_LIST, UI_SCROLL_F_NO_FLING);   /* 只有跟手，不要惯性 */
```

| 模式 | 停稳后 | 适用 |
|---|---|---|
| `UI_SCROLL_LIST` | 对齐整行（`row_px`）| 设置页、文件列表、应用列表、收藏夹 |
| `UI_SCROLL_PIXEL` | 停在任意像素 | 阅读器正文、终端输出、大图浏览 |
| `UI_SCROLL_PAGE` | 对齐整页（`view_px`），过半页才翻 | 电子书、漫画、说明书 |

| 开关 | 作用 | 适用 |
|---|---|---|
| `UI_SCROLL_F_NO_FLING` | 松手立刻停，无惯性 | 精确对位的滑块、参数调节 |
| `UI_SCROLL_F_NO_BOUNCE` | 硬边界，拉不出半屏 | 嵌入小窗的局部滚动 |
| `UI_SCROLL_F_HORIZ` | 主轴换成 x（配合 `ui_scroll_touch_xy`）| 横向图标行、时间轴 |
| `UI_SCROLL_F_LOOP` | 到头接尾 | 轮盘选择、环形菜单 |

> 开关可叠加：`ui_scroll_config(&sc, UI_SCROLL_PIXEL, UI_SCROLL_F_HORIZ | UI_SCROLL_F_NO_BOUNCE)`

## 手感（已定死，不要各页调参）

| 项 | 值 |
|---|---|
| 拖动阈值 | 12px（低于此算点击）|
| 跟手 | 1:1，越界最多拉出半屏 |
| 松手惯性 | 每帧 ×0.86，<0.4px 停，限速 ±60px |
| 越界回弹 | 每帧 ×0.8，<2px 归零 |
| 行吸附 | `row_px > 1` 停稳吸附整行；`row_px = 1` 像素级 |

## 接入（一个页面只要这 8 行）

```c
#include "ui_scroll.h"

static ui_scroll_t s_sc;            /* ① 页面私有 */

/* ② 进页面 / 内容变化时 */
ui_scroll_init(&s_sc, ROW_H, VIEW_H, count * ROW_H);

/* ③ poll 里每帧: 喂触摸 + 推进惯性 */
int tx, ty;
bool down = input_get_touch_pos(&tx, &ty);
if (ui_scroll_touch(&s_sc, ty, down)) ctx->needs_redraw = true;
if (ui_scroll_poll(&s_sc))            ctx->needs_redraw = true;

/* ④ 拖动中屏蔽点选/长按 */
if (ui_scroll_dragging(&s_sc)) return;

/* ⑤ 滚动未收敛时不要重排整页（这是"跟手"的关键） */
if (ui_scroll_busy(&s_sc)) return;

/* ⑥ 渲染: 内容起点 */
int y0 = LIST_Y - ui_scroll_offset(&s_sc);

/* ⑦ 可选: 统一滚动条 */
ui_scroll_drawbar(&s_sc, lcd, 396, LIST_Y, LIST_Y + VIEW_H);

/* ⑧ 切分类 / 换目录 / 退页面 */
ui_scroll_to_top(&s_sc);      /* 回顶部 */
ui_scroll_cancel(&s_sc);      /* 退页面清状态 */
```

## API

| 函数 | 用途 |
|---|---|
| `ui_scroll_config(s, mode, flags)` | 选模式与开关（进页面前调一次）|
| `ui_scroll_init(s, row_px, view_px, content_px)` | 初始化/内容变化（保留当前位置）|
| `ui_scroll_set_content(s, content_px)` | 只改内容高度 |
| `ui_scroll_touch_xy(s, x, y, down)` | 喂触摸（横向模式自动取 x）|
| `ui_scroll_touch(s, y, down)` | 竖向便捷版 |
| `ui_scroll_poll(s)` | **每帧**推进惯性/回弹，返回是否重绘 |
| `ui_scroll_dragging(s)` | 是否在拖动（屏蔽点击）|
| `ui_scroll_busy(s)` | 拖动/惯性/回弹未停（跳过底层重绘）|
| `ui_scroll_offset(s)` | 渲染偏移（`off + sub`）|
| `ui_scroll_first_row(s)` | 首个可见行（渲染裁剪）|
| `ui_scroll_max(s)` | 最大偏移 |
| `ui_scroll_ensure_visible(s, item_y, item_h)` | 按键选中时把它滚进可视区（已可见不动）|
| `ui_scroll_to_top(s)` / `ui_scroll_cancel(s)` | 回顶 / 清状态 |
| `ui_scroll_drawbar(s, lcd, x, y0, y1)` | 点阵渐隐滚动条 |

## 禁止

- ⛔ 自己写 `drag_last_y` / `fling` / 吸附逻辑
- ⛔ 滚动期间重排整页（必须 `ui_scroll_busy()` 提前 return）
- ⛔ 在滚动条上画整条实线（用 `ui_scroll_drawbar`）
- ⛔ 各页面自调惯性/回弹系数

| 页面 | 模式 | 说明 |
|---|---|---|
