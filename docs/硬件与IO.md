# 硬件与 IO

> ESP32-S3-RLCD-4.2（步步高词典）模块化掌机的硬件平台信息。
>
> ## ★ 板级总览（3 块板 / **2 个固件目标**）
>
> | 板 | 固件目标 | 说明 |
> |---|---|---|
> | **微雪 ESP32-S3-RLCD-4.2 官方版** | **目标 A** | 本文档的主线 |
> | **我 DIY 的版本** | **目标 A（同）** | ⭐ **与微雪引脚兼容** —— 同一套 GPIO、同一套音频方案 ⇒ **同一份固件**，靠 `es8311_is_present()` 运行期识别 |

> 早期还有一版 DIY 用 **NS4168** 数字功放（见下方"音频"一节的历史备注），现行 DIY 版已与微雪统一。

## 芯片与存储
- **主控**：ESP32-S3-WROOM-1-N16R8（240MHz 双核 / 16MB Flash / 8MB PSRAM）
- **PSRAM**：8MB octal 80MHz（`CONFIG_SPIRAM_MODE_OCT` / `CONFIG_SPIRAM_ALLOW_BSS_SEG_EXTERNAL_MEMORY`）— 占用 GPIO33-37，不可他用
- **Flash**：16MB QIO（`CONFIG_ESPTOOLPY_FLASHMODE_QIO`）— 占用 GPIO26-32（模组内部）

## 显示屏
- **ST7305 反射式 1-bit LCD**，400×300，帧缓冲 15KB（PSRAM）
- ★ **没有背光**（反射屏靠环境光读，**静态几乎不耗电**，只在刷新时耗电；固件里也没有背光脚）
  ⇒ 屏对 `3V3` 的电流压力**可以忽略**，别把它算进 200mA 预算里
- 引脚：`RLCD_DC=GPIO5`、`RLCD_SCK=GPIO11`、`RLCD_MOSI=GPIO12`、**`RLCD_CS=GPIO42`**、`RLCD_RST=GPIO41`
  - ⚠ **2026-10-04**：核心换**小智 ESP32-S3 模块**（自带功放+喇叭+麦），模块占了 **IO40**
    ⇒ 屏 CS 由 40 挪到 **42**。详见 `docs/小智S3核心模块-引脚调整.md`

## 触摸
- CST816 / GT911 / FT6236（I2C_NUM_1，`tp_probe_chip` 自动识别）
- I2C：`SDA=GPIO15`、`SCL=GPIO7`、`INT=GPIO17`、`RST=GPIO2`
- ⚠️ 官方板无触摸，触摸为自制板新增（飞线面板）

## SD / TF 卡

**SDMMC 1-bit**（硬件控制器 + DMA，**不是 SPI**），挂载 `/sdcard`。代码真相源 = `sd_scan.c`。

### ① 8 个触点怎么接（一张表看完）

> 缺口朝左下、触点朝下，从左往右数 1~8。**到 MCU 的只有 3 根线**（触点 3 / 7 / 5）。

| 卡座触点 | 名称 | 这根线接到哪 | 上拉电阻 | 附加 |
|---|---|---|---|---|
| **1** | DAT2 | **不接**（不进 MCU） | **10k → 3V3** | — |
| **2** | DAT3 | **不接**（不进 MCU） | **10k → 3V3** | ⚠ **最常漏的一颗** |
| **3** | CMD | 一根线 → **MCU 的 1 个 IO** | **10k → 3V3** | — |
| **4** | VDD | **3V3** | — | 旁边挂 **0.1µF + 10µF + 100µF** 到 GND |
| **5** | CLK | **中间串 22~33Ω**（电阻摆 MCU 那端）→ **MCU 的 1 个 IO** | ⛔ **不接** | — |
| **6** | VSS | **GND** | — | — |
| **7** | DAT0 | 一根线 → **MCU 的 1 个 IO** | **10k → 3V3** | — |
| **8** | DAT1 | **不接**（不进 MCU） | **10k → 3V3** | — |
| 金属外壳脚 ×2~4 | 屏蔽 | **GND（每个都要接）** | — | — |

**总计** = 3 根信号线（触点 3 / 7 / 5）+ **5 颗 10k 上拉**（触点 3 / 7 / 2 / 1 / 8）
+ **1 颗 22~33Ω 串阻**（CLK）+ **3 颗电容**（VDD）+ 地线（触点 6、外壳、电容负端）。

- **触点 1 / 2 / 8 看着没用，但必须挂上拉** —— 漏了就会"时好时坏"。
- 卡座 CD 检测开关：不接也能用（走软件探测）；想接就 +1 个 IO，再挂一颗 10k 上拉，软件 20~50ms 去抖。

> 本工程当前取值（可改，同步 `sd_scan.c` 顶部三个宏）：**CMD=GPIO10 / CLK=GPIO13 / D0=GPIO14**（3 个 IO）。

### ② 五条不能错

1. **触点 2 不能接地、不能悬空** —— 它是"协议选边站"：上电时卡读到**高 = 走 SD 协议**、
   **低 = 掉进 SPI 协议**。悬空 ⇒ 电平随机 ⇒ 时好时坏；接地 ⇒ **永远**挂不上
   （网上"CS 接地"那套是 **SPI 玩法**）。
2. **触点 1 / 8 也不能悬空** —— 官方要求 1-bit 模式下 **`CMD` + `DAT0~DAT3` 五根全部 10k 上拉**
   （*"regardless of whether these lines are connected to the host"*），否则卡会进错误状态。
3. **CLK 不上拉**；`22~33Ω` 串阻是 **可选项，不是必须** —— 作用是**源端端接**压振铃
   （让 `GPIO内阻 + R` ≈ 走线阻抗 ≈ 50Ω）。**什么时候才加**：走线长 / 有飞线排线 /
   要**降频才挂得上** / 示波器看到过冲。⚠ 加的话必须**靠 MCU 端**，放卡端无效。
   不加的等价手段：`gpio_set_drive_capability(<CLK脚>, GPIO_DRIVE_CAP_1)` 降一档驱动
   （须在 `sdmmc_host_init_slot()` **之后**调）。
4. **卡座屏蔽脚全部接地** —— 只接一个是历史上 brownout 的成因之一。
5. **别指望内部上拉** —— IDF 原文：*"internal pullups **are insufficient** … make sure **external**
   pullups are connected"*。

### ③ 电源：一读就重启的真凶

卡座 VDD 就近 **0.1µF（≤3mm）+ 10µF + 100µF**。读卡峰值 **200mA**（IDF 排错清单口径）。
历史故障：整条 3V3 只有两颗 0603 电容 ⇒ 读卡瞬间跌落 ⇒ **BROWNOUT 复位**。
判据：示波器看读卡瞬间 3V3 跌落 **<100mV**。

### ④ "插着卡说没读到" 的两个真因

| 真因 | 治 |
|---|---|
| **卡自己卡死**在内部状态（IDF：不 power-cycle 就复位，卡可能**不作答**）⇒ 软复位 / 重新挂载都没用 | **卡座 VDD 串 P-MOS，软件断电 100ms 再上电**（占 1 个 IO） |
| 3V3 被读卡峰值拉跌 | 见 ③ |

### ⑤ 三种接法选哪个

| | ① **SDMMC 1-bit ← 本项目** | ② SDMMC 4-bit | ③ SPI 模式 |
|---|---|---|---|
| 线数 | **3** | 6 | 4 |
| 速度 | 4-bit 的 ~80% | **最快**（读 8.4 MB/s） | ~4-bit 的 50%（读 1.67 MB/s） |
| 何时用 | **引脚紧 + 速度够 = 默认** | 读大图 / 音视频 | 引脚被占死 / 要与别的 SPI 设备共享总线 |

> 只有 **ESP32 / S3 / P4** 有 SDMMC 外设（C3 / C6 / H2 只能走 SPI）。S3 的信号脚**可任意映射**
> （官方原话），只需避开：**GPIO0 / 45 / 46**（strapping）、**26~32**（flash/PSRAM）、
> **33~37**（八线 flash/PSRAM 模组占用）、**43 / 44**（UART0）、**19 / 20**（USB）。

### ⑥ 软件侧现状（2026-10-05 核实代码）

- `sd_watcher_start()` 开头一句 `return;` ⇒ **自动补挂被彻底禁用**，换卡后必须**手动**走菜单「重新挂载TF卡」。
- `sd_op_watchdog_begin/end` 已是**空实现**（卡死无兜底）。
- `slot.cd` / `slot.wp` 都是 `-1`（不用硬件检测）。音频 I2C0 走模块内部 **38 / 47**，与 TF **无冲突**。

### ⑦ 上拉自检（IDF 自带，不用示波器）

menuconfig → `SD/MMC → Debug sd pin connections and pullup strength`：
**50~300 cycles 回高 = 上拉真接上了**；10000 cycles 超时 = 悬空。
万用表版：触点 1 / 2 / 3 / 7 / 8 各自对 3V3 都应约 **10k**，触点 2 对 GND 应**高阻**。

## 音频（两板一固件：同一路 I2S，零判断）

> V1.0.70 起：官方板 ES8311 与自制板 NS4168 **都吃 I2S 数字信号**，
> 固件按 `es8311_is_present()` 自动识别平台，数据路径完全一致，无需硬件跳线。

### 官方板（微雪 ESP32-S3-RLCD-4.2）
- **audio_player（I2S → ES8311 codec → AAXS2005 功放 → 喇叭）**：
  `BCLK=GPIO9`、`WS=GPIO45`、`DOUT=GPIO8`、`MCLK=GPIO16`、`PA_EN=GPIO46`（高=功放开）
- **ES7210 双麦克风阵列**（I2S RX）：`DIN=GPIO10`

### 自制板（NS4168 I2S 数字功放，⚠️ 本次新增接线）
- **audio_player（I2S → NS4168 直接放大，零配置）**：与官方板**同一路 I2S**
  `BCLK=GPIO9`→NS4168 BCLK、`WS=GPIO45`→NS4168 LRCLK、`DOUT=GPIO8`→NS4168 SDATA
  `CTRL=GPIO46`（高=工作/右声道，低=关断静音）
- ⚠️ NS4168 为 **I2S 数字输入**功放（ESOP8），**无需 MCLK**（GPIO16 可不接）、无输入耦合电容；
  数据直接来自 ESP32 I2S DOUT，芯片自动提取 BCLK/LRCLK/SDATA 解码。
- ⚠️ VDD（Pin6）直接接**电池 3.7V**（NS4168 工作范围 3.0~5.5V，3.7V 约出 1.3W@4Ω；如需最大 2.5W 可改接 5V）

**NS4168 ESOP8 引脚接线表（自制板）：**
| NS4168 引脚 | 接法 | 说明 |
|---|---|---|
| Pin1 CTRL | ← GPIO46 | 高=工作（右声道），低=关断（静音省电） |
| Pin2 LRCLK | ← GPIO45 (I2S_WS) | I2S 帧时钟 = 采样率 |
| Pin3 BCLK | ← GPIO9 (I2S_BCLK) | I2S 位时钟 |
| Pin4 SDATA | ← GPIO8 (I2S_DOUT) | I2S 数据（2's 补码） |
| Pin5 VoN | → 喇叭 - | 输出负端 |
| Pin6 VDD | ← 电池 3.7V | 电源（3.0~5.5V） |
| Pin7 GND | → GND | 地 |
| Pin8 VoP | → 喇叭 + | 输出正端 |

- **tone_player（按键音/开机音/暴龙机音效）**：V1.0.70 改走 **PCM 合成 → I2S**，
  不再用 GPIO6 方波飞线（GPIO6 已释放为**闲置 IO**）。
  官方板经 ES8311、自制板经 NS4168，同一路 I2S 均出声，不绑定任何引擎。
- ⚠️ V1.0.69 曾把 tone_player 从 GPIO48 移到 GPIO6（因 48 与震动 EN 同脚冲突）；
  V1.0.70 起 tone 走 I2S 后 GPIO6 空闲、GPIO48 归震动 EN 专用。

## 震动（⚠️ 自制板新增，官方板无此功能）
- **TM6604 线性驱动**（SOT23-6，PWM 直驱 LRA，无寄存器上电即用）：
  - **`PWM=GPIO6`**（LEDC TIMER_1/CH1，190Hz = LRA 谐振；**代码真相源** `vibrator.c VIB_PWM_PIN`）
    - ⚠ 2026-10-04 起为 **GPIO6**（原 `PWM=42`+`EN=48` 两根线）。42 让给了屏 CS，
      `EN` 路径删除（新板**震动电源常开**）。⚠ 48 曾试过但**作废** —— 48 是 `VSYS_OUT`（电源通路），
      不能拿 PWM 去斩。完整依据见 `docs/小智S3核心模块-引脚调整.md`
  - OUT±（Pin1/3）接 LRA；Pin2 GND、Pin4 VDD
- ★ **供电：马达直接接电池（VBAT），不经模块 3V3** ⇒ **不占 3V3 的 200mA 预算**
  - ⛔ 但由此带两个板级设计要求：
    ① **MOS 栅极必须有 10kΩ 下拉到 GND** —— 上电到 `vibrator_init()` 之间 GPIO6 是**浮空**的，
       没有下拉可能让马达**开机瞬间误导通**（固件管不到那几十毫秒）
    ② **VBAT 就近加大电容（100~470µF）+ 马达端续流二极管** —— 马达浪涌会造成**电池侧压降**，
       本仓有"负载突变掉电复位"的前科，震动一下重启是这类问题的经典症状
- 强度：`out_set(0~100)` → 占空比 0~255（VIB_RES_MAX）

### V1.4.x 触发方式（三档互斥，后发起停前者）
1. **单次 tap**（`vibrator_tap`）：按键/菜单导航/拖动反馈，保持快速响应。
2. **预设花样**（`vibrator_play_pattern`）：段式序列（时长+强度），非阻塞定时器逐段推进。
   内置花样库（`vibrator.h` 直接引用）：
   | 花样 | 内容 | 用途 |
   |---|---|---|
   | `VIB_PAT_TICK` | 60ms 短促 | 轻反馈 |
   | `VIB_PAT_DOUBLE` | 50+60+50ms 双敲 | 确认 |
   | `VIB_PAT_HEARTBEAT` | 90+60+140ms 强弱心跳 | 提示 |
   | `VIB_PAT_SUCCESS` | 三连渐强 | 番茄钟完成 |
   | `VIB_PAT_ERROR` | 低鸣两下+长震 | 报错 |
   | `VIB_PAT_SOS` | 摩尔斯 SOS（3短3长3短） | 求救演示 |
   | `VIB_PAT_RAMP_UP/DOWN` | 5 段渐强/渐弱 | 音量/特效 |
   | `VIB_PAT_ALARM` | 300+180ms **无限循环** | 闹钟（关铃即停） |
   | `VIB_PAT_CLICK` | 18+22+16ms 按下+释放双脉冲 | 按键模拟（触摸点击） |
4. **齿轮震动**（主菜单，V1.4.x）：拖动或惯性滑行中每跨过一个居中图标
   触发一次 10ms/100 短促高强脉冲（"咔哒"手感）；覆盖 fling 松手后的
   惯性动画段（此前全程静默），快速甩动次数与划过的图标数一致；
   25ms 防抖合并同帧跳格，脉冲清晰不粘连。
   - 甩动动画用**抛物线缓出** `1-(1-t)^2`（速度线性衰减），每格 130ms、
     上限 1600ms → 末段减速滑行更长，最后还能慢慢滑过 2-3 格才停。
   - **收尾渐慢**：动画剩余 ≤650ms 进入尾段，跨格震动间隔 = 上一格实际
     间隔 ×1.5 自适应递增（限 90~300ms）——动画快自动拉长间隔、动画慢
     跟格即震，从 ~100ms 平滑渐至 ~300ms，收尾"哒…哒…哒"渐慢不突停。
5. **按键模拟**（`vibrator_click`，V1.4.x）：**按下瞬间立即震动**（TG_IDLE
   按下沿触发，零延迟），模拟机械按键"按下去"的段落感（苹果触控板式）；
   按住 >0.5s 松手再补一次"弹起"震动（`TOUCH_HOLD_VIB_MS 500`），快速
   点击只震一声。覆盖所有触摸按下（页面/弹窗按钮/主菜单图标/拖动起点）。
   设置页"声音震动 → 按键模拟"可关（关后回退为普通 UI tap），NVS
   `vib_key` 持久化；跟随 UI 震动总开关。
   - **上下文屏蔽**：主菜单/软件管家页**直接内容**不震（拖动图标/管理列表
     保持干净）——os_core `os_tick` 每帧按 `current_page + modal_active`
     驱动 `input_set_key_sim_ctx_block`；弹窗覆盖时自动恢复（弹窗内点击
     仍有按键感），二级页面/软件程序照常震动。
3. **随音乐震动**（`vibrator_music_mode`）：MP3/游戏 PCM 两路喂振幅表
   （`audio_player_get_meter`，0..1000），内部任务每 20ms 采样，死区 6% 后
   线性映射 PWM 强度——听歌/游戏时马达随节奏震动。
   MP3 播放页新增"随音乐震动"按钮（循环按钮右侧，黑底=开，NVS `mp3/vib_music` 持久化）。

## 电池与充电

### 电池采样（ADC）
- **电池 ADC：`GPIO4`（ADC1_CH3）**，经分压电阻接 VBAT；固件系数 `÷3`（`board_battery.c`）。
- **分压阻值以实物为准，文档与代码注释不一致，已记录**：

| 来源 | 阻值 | 说明 |
|---|---|---|
| `board_battery.c` 注释 | 2M / 1M | 自制板 |
| 本文件早期版本 | 200K / 100K | 与微雪官方板一致 |

> **两者比值都是 2:1 → ÷3，固件系数正确，功能不受影响**；但**绝对阻值影响 ADC 精度**：
> 2M 源阻抗会让 ESP32-S3 ADC 系统性读**偏低**（满电观感"少一格"的加重因素）；
> 200K/100K（源阻抗 ≈67kΩ）则无此问题。
> **待办**：核实实物阻值；若确为 2M/1M，建议下次改板换 200K/100K，或在 ADC 脚并 100nF。

### 板型识别（开机最早做，早于一切外设初始化）
- 判据只看 **ES7210**（小智独有）：有 → 小智；没有 + 有板载器件(QMI8658C 0x6A/6B 或 RTC 0x51/0x32) → 微雪；
- ⛔ **别把 ES8311(0x18) 当必要条件**：地址由 CE 脚决定，微雪板上 0x18 实测无应答，加了会识别失败；
- 探针带 3 次重试 + 两条总线交叉判定；结果写 NVS 缓存，每次开机做一次轻量校验（两块板来回换不会认错）。
