# 硬件 / PCB 工程

## 文件

| 文件 | 说明 |
|---|---|
| `LinTOS_2026-10-19.epro` | **嘉立创 EDA 专业版工程文件**（原理图 + PCB） |
| `images/pcb-xiaozhi.png` | **小智集成板** 3D 渲染图 |
| `images/pcb-standard.png` | **标准扩展板** 3D 渲染图 |
| `schematic.pdf` | **两版完整原理图**（PDF，可直接看/打印/对照维修）|

> 工程文件对应固件 **v1.4**。以原理图为准；如元件库缺失，重新指定封装即可（不影响电气连接）。

## 怎么用

1. 打开 **嘉立创 EDA 专业版**（免费，网页版/客户端均可）→ `文件 → 导入 → 嘉立创EDA(专业版)`
2. 选择 `LinTOS_2026-10-19.epro`
3. 确认 DRC → `制造 → 导出 Gerber` → 直接下单打样（嘉立创）

> 只想要固件、不自己打板：直接下 `LinTOS-v1.4-16MB.bin` 刷到现成硬件（见仓库 Release）。
> 已有微雪原板（ESP32-S3-RLCD-4.2）可直接刷，无需任何改动。

## 原理图能用来做什么

`schematic.pdf` 是**两版的完整原理图**（含元件标号、网络连接、封装），可以用来：

- **照着自己搭** —— 不买成品板，按图逐段接线/买元件
- **修板** —— 量点对照、查某个信号该通到哪、换件时确认型号
- **改板** —— 在 `.epro` 工程里直接改，或按 PDF 在别的 EDA 里重画
- **核对固件引脚** —— 与 [主 README 的引脚表](../README.md#硬件说明) 一一对应

> 原理图 + `.epro` + 渲染图 + 采购清单 = 完整的一套，照着就能做出一台。

## 识别方式

同一份固件开机自动探测 I2C 上的芯片指纹判定板型：`38/47 有 0x18(ES8311)` → 小智集成板 ·
`13/14 有 0x18` → 微雪原版 · `15/7 有 0x15(CST816)` → 标准扩展板。
未检测到的硬件不初始化（例如没焊 GPS 就不占用串口），也可在「设置 → 网络与系统 → 硬件管理」手动开关。
